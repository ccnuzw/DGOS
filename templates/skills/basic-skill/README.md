# My Basic Skill

A basic skill template for DGOS V1.

## Overview

This skill processes text input and returns transformed results.

## Installation

```bash
dgos skill install ./
```

## Usage

### Trigger Examples
- `myskill execute`
- `run myskill`

### Parameters
- `input` (string, required): Input text to process

## Development

### Testing
```bash
dgos skill test
```

### Building
```bash
dgos skill package
```
