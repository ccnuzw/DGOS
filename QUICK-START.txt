                            PREREQUISITES
================================================================================

System Requirements:
- OS: macOS 12+, Linux (Ubuntu 20.04+), Windows 10+ WSL2
- Memory: 4GB minimum, 8GB recommended
- Disk: 2GB free space
- Network: Internet connection

Required Software:
- Docker 20.10+
- Docker Compose 2.0+
- Node.js 22.0+
- pnpm 9.0+
- Git 2.30+

Quick Version Check:
  $ docker --version
  $ docker compose version
  $ node --version
  $ pnpm --version
  $ git --version

Installing Missing Software:

  Docker & Docker Compose:
    macOS/Windows: Download Docker Desktop
    Linux: curl -fsSL https://get.docker.com | sh

  Node.js v22:
    $ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
    $ nvm install 22
    $ nvm use 22

  pnpm:
    $ npm install -g pnpm@9
    or
    $ corepack enable && corepack prepare pnpm@9.0.0 --activate

================================================================================
              PATH A: DOCKER COMPOSE (RECOMMENDED - 5 MINUTES)
================================================================================

Perfect for: Quick evaluation, production-like environment

Step 1: Clone Repository
  $ git clone https://github.com/your-org/DGOS.git
  $ cd DGOS

Step 2: Configure Environment
  $ cp .env.example .env

  (Default configuration works out of the box)

Step 3: Start Infrastructure
  $ docker compose up -d

  Verify services:
  $ docker compose ps

  Expected: postgres and redis showing "Up (healthy)"

Step 4: Install Dependencies (2-3 minutes)
  $ pnpm install --frozen-lockfile

Step 5: Run Database Migrations
  $ pnpm migrate:plan

Step 6: Start DGOS

  Terminal 1:
  $ pnpm --filter @dgos/api dev

  Terminal 2:
  $ pnpm --filter @dgos/web dev

Step 7: Access DGOS
  Web UI:    http://127.0.0.1:5173
  API:       http://127.0.0.1:3000
  Health:    http://127.0.0.1:3000/health

SUCCESS! DGOS is now running.

================================================================================
                        FIRST TIME SETUP
================================================================================

1. Bootstrap Administrator Account

   Via Web: http://127.0.0.1:5173/setup

   Via API:
   $ curl -X POST http://127.0.0.1:3000/admin/bootstrap \
     -H "Content-Type: application/json" \
     -d '{
       "username": "admin",
       "password": "YourSecurePassword123!",
       "email": "admin@example.com"
     }'

   Password Requirements:
   - Minimum 12 characters
   - Mix of uppercase, lowercase, numbers
   - Special character recommended

2. Configure First Provider

   Navigate to: Settings > Providers > Add Provider

   Example OpenAI:
   {
     "name": "OpenAI GPT-4",
     "protocol": "openai-compatible",
     "baseUrl": "https://api.openai.com/v1",
     "apiKey": "sk-...",
     "defaultModel": "gpt-4"
   }

   Testing with Fixture:
   $ pnpm provider:fixture
   (Use the baseUrl and token from output)

3. Install First Package (AI Workbench)

   Via Web:
   - Navigate to Catalog > Packages
   - Find "AI Workbench"
   - Click Install
   - Click Launch

4. Create First Task

   From Workbench:
   - Click "New Task"
   - Enter: "Summarize the key features of DGOS"
   - Select Provider: "OpenAI GPT-4"
   - Click "Run"

5. View Results

   Results appear in output panel
   View execution logs in sidebar
   Export as JSON or text

  $ docker compose exec -T postgres psql -U dgos dgos < backup.sql

================================================================================
                        TROUBLESHOOTING
================================================================================

Services Won't Start:
  $ docker ps
  $ docker compose down -v
  $ docker compose up -d

Database Connection Error:
  $ docker compose ps postgres
  $ docker compose exec postgres pg_isready -U dgos -d dgos
  $ docker compose restart postgres
  $ docker compose logs postgres

Port Already in Use:
  $ lsof -ti:3000
  $ kill -9 $(lsof -ti:3000)
  or change PORT in .env

Migration Failed:
  $ pnpm migrate:check
  $ pnpm migrate:sql

  Reset (WARNING: destroys data):
  $ docker compose down -v
  $ docker compose up -d
  $ sleep 10
  $ pnpm migrate:plan

pnpm Install Fails:
  $ pnpm store prune
  $ rm -rf node_modules pnpm-lock.yaml
  $ pnpm install

Web UI Shows White Screen:
  1. Check dev server: pnpm --filter @dgos/web dev
  2. Open browser DevTools > Console
  3. Hard refresh: Ctrl+Shift+R or Cmd+Shift+R
  4. Rebuild: pnpm --filter @dgos/web build

Permission Denied:
  $ sudo chown -R $(whoami) node_modules

  Linux Docker socket:
  $ sudo usermod -aG docker $USER
  (then log out and back in)

Out of Memory:
  $ export NODE_OPTIONS="--max-old-space-size=4096"
