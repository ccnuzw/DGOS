# Context-pack：WP-W2-07 FR-009 助手 UI

## 目标

补齐官方助手 Web UI：快捷指令、动作发现、计划/风险确认、执行/取消/失败与历史恢复。

## 当前事实

- FR-009 为“基础实现”；Action resolver、fresh Session、确认、权限和原子设置已有后端/局部浏览器证据。
- 主要差距是 UI 对齐 requiredCapabilities、逐项授权，以及导航/确认/拒绝/取消/生命周期和 Run 恢复的双宿主链。

## 权威规格

- `docs/03-功能规格/V1/09-系统助手/01-系统智能助手与快捷指令.md`
- `docs/03-功能规格/V1/09-系统助手/02-系统智能助手与动作执行-技术设计.md`

## 核心约束

- 助手只选择当前主体可见、安装、启用、健康且授权的 action。
- 写入、权限、秘密、网络、模型调用等副作用必须计划并明确确认。
- Provider 不可用时快捷指令仍工作；自然语言失败不得猜测执行。
- 执行前重新鉴权；长任务使用 taskId/runId，支持取消/恢复。
