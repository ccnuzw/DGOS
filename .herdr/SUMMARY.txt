## Key Features

### Capability Classification
```typescript
// Models can have multiple capabilities
{
  modelId: 'gpt-4',
  capabilities: ['text', 'image-understanding', 'multimodal']
}
```

### Default Model Management
```typescript
// Only one default per capability
{
  modelId: 'gpt-4',
  defaultForCapability: 'text',
  enabled: true
}
```

### Advanced Filtering
- Search: "gpt" → filters by ID/name
- Filter: "text" → shows only text-capable models
- Combined: Search "gpt" + Filter "text" → GPT text models only
- Unclassified: Shows models without capabilities

## User Workflows

### Classify and Enable Model
1. Select Provider
2. Click "Configure" on model
3. Select capabilities (checkboxes)
4. Click "Save Capabilities"
5. Click "Enable"
6. Model appears in task selector

### Set Default Model
1. Filter to capability (e.g., "text")
2. Configure desired model
3. Select "Set as Default for" → "Text Generation"
4. Previous default cleared automatically
5. New default set with badge

### Refresh Catalog
1. Select Provider
2. Click "Refresh Catalog"
3. Catalog version increments
4. New models added
5. User classifications preserved
