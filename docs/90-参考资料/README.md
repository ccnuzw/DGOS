# 参考资料

## 证据限制

视频音轨为独立 AAC 文件，已核对与视频时长对齐；当前环境没有本地语音识别工具，因此文字证据以画面内中英烧录字幕和界面状态为主，不把未经转录的口述扩展为需求。
