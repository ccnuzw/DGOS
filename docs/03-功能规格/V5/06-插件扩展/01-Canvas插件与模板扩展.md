## 目标

开发者可以提供节点、端口、执行器和模板扩展；创作者可以查看权限和版本，安装、启用、升级、停用或卸载，并在画布中使用。

## 功能边界

包含：插件清单、节点注册、插件命名空间、ComfyUI/工作流扩展节点、隔离存储、版本检查、安装/启用/升级/卸载和画布节点生命周期。

不包含：未知脚本自动执行、绕过清单的动态注入和插件市场运营。

## 完成定义

一个示例插件可按公开 SDK 注册节点，受权限控制地运行，升级/卸载后不遗留不可访问数据。

## 需求说明

### 用户故事

作为开发者，我希望通过公开 DGOS SDK 扩展画布，而不修改系统内部；作为创作者，我希望知道扩展版本和风险。

### 业务规则

1. 节点声明、端口和执行器必须符合协议版本和 schema。
2. 插件数据使用 DGOS 分配的隔离存储，不读写其他插件或 DGOS 系统服务私有目录。
3. 升级失败保留旧版本；卸载前明确数据处理结果。
4. 插件节点类型必须位于插件命名空间；新插件不能覆盖已有插件的提示、节点类型或执行器。
5. ComfyUI/工作流适配必须通过公开 DGOS 扩展入口登记，不能复制旧项目私有协议或直接覆盖 DGOS 工作流定义。
6. Canvas Agent 节点声明必须包含稳定类型、版本、语义角色、输入/输出 schema、可接受的画布输入和执行适配器；宿主统一注册和渲染节点状态。
7. 手动运行和 Agent 运行必须进入同一个 Canvas Executor；插件不能为 Agent 另建一套绕过权限、超时、取消或审计的执行路径。
8. 插件停用或缺失时，已有画布保留节点配置和版本快照并显示 `disabled`/`missing`，恢复依赖后再允许重新绑定。

### 主流程

1. 从注册表或受信 URL 查看插件详情。
2. 校验包、协议、权限和版本。
3. 安装并注册节点/模板。
4. 在画布中创建节点并执行。
5. 将 ComfyUI/工作流节点与画布输入输出连接。
6. 升级、停用或卸载。

### 异常与边界

- 协议不兼容/权限缺失：禁止启用。
- 执行失败：节点进入 error，不能污染其他节点。
- 升级/卸载中断：恢复上一个可用状态。

### 页面与交互

插件面板展示名称、版本、来源、权限、更新提示、启用状态和失败原因；节点面板显示扩展来源、命名空间和协议版本。由画布右键将选中节点加入模板库时，先预览模板结构、依赖、权限和数据范围；移除 API Key、完整媒体和 DGOS 系统服务私有路径后才允许保存。

### 领域数据语义

插件包、注册信息、隔离数据和画布节点引用分开管理；画布只保存稳定的扩展身份和节点配置。

### 本版本不做

不承诺第三方插件永久兼容，协议升级需重新验证。

## 接口契约

采用公开 DGOS Canvas Plugin SDK、Extension Runtime 和 Permission API；不实现 DX OS 或旧项目远程节点私有协议。

Canvas Agent 的声明、动作目录和执行器输入输出属于 V3-V5 设计输入；V1 只冻结扩展注册、权限和缺失状态的边界，不提前交付第三方插件运行时。

### 接口清单

V1 只冻结扩展注册、权限和缺失状态边界；插件安装、运行、模板和 Agent action API 均为 V3-V5 规划接口。

### OpenAPI operation 映射

不适用：V1 OpenAPI 没有 Canvas Plugin/Extension operationId；未来版本冻结 schema 后再建立映射，不复用其他领域的 operationId。

### 错误矩阵

| 场景 | 规划错误语义 | 处理要求 |
| --- | --- | --- |
| 扩展声明无效 | `invalid_manifest` | 拒绝注册并定位声明字段 |
| capability 未授权 | `permission_denied` | 执行前拒绝并审计 |
| 扩展缺失/版本失效 | `extension_unavailable` | 保留原引用，不静默替代 |

## 数据与事务

安装/升级/卸载是可回滚的生命周期操作；节点执行状态与插件安装状态分离。

### 涉及数据

未来扩展 manifest、版本、签名、权限声明、模板、扩展数据空间、运行状态和审计；V1 不安装第三方插件运行时。

### 约束与事务

扩展安装/升级/卸载需可回滚；模板导入须校验来源和 schema；执行状态与安装状态分开维护。

### 字段读写矩阵

| 数据 | Extension Runtime | 插件 | Canvas/项目服务 |
| --- | --- | --- | --- |
| manifest/权限 | 校验和固化 | 声明 | 只读摘要 |
| 扩展私有数据 | 隔离存储 | 限定读写 | 不可读 |
| 项目/节点字段 | 授权代理 | 按 capability 操作 | 权威持有 |

### 状态与生命周期

扩展：`registered` -> `installed` -> `enabled`/`disabled` -> `uninstalled`；运行：`starting` -> `ready`/`failed` -> `stopped`。

### 物理约束与迁移

manifest、扩展数据和模板均版本化；升级需声明迁移并支持失败回滚；扩展存储空间按 appId/extensionId 隔离。

### 数据所有权

DGOS Extension Runtime 拥有安装和运行记录；插件拥有声明内容及隔离数据；项目服务拥有项目和节点数据。

### 安全与保留

能力由 Permission 服务裁定；隔离扩展不得读取其他扩展数据或秘密；审计脱敏，卸载清理运行数据并按策略保留必要审计。

## 验收标准

#### AC01 安装并运行节点

Given 插件包通过协议和权限校验。

When 用户启用插件并在画布创建节点。

Then 节点出现在注册表中，按输入 schema 运行并显示结果或错误。

#### AC02 升级失败回滚

Given 新插件版本校验失败或健康检查失败。

When 用户执行升级。

Then 旧版本保持可用，插件数据和画布引用不被破坏。

#### AC03 命名空间与工作流扩展隔离

Given 两个插件分别声明普通节点和 ComfyUI/工作流节点。

When 用户安装并在同一画布中使用它们。

Then 节点类型保持各自命名空间，插件不会覆盖已有插件的提示或执行器，工作流输入输出按声明协议连接。

#### AC04 选中节点加入模板库前置校验

Given 用户选中一组节点并请求将其加入模板库，节点配置可能包含秘密、媒体或 DGOS 系统服务私有路径。

When 系统生成模板预览并执行保存。

Then 显示节点结构、依赖、权限和数据范围，过滤敏感字段；校验失败时不写入模板且原画布不变。

### 回归要求

- 插件不得访问其他插件、DGOS 私有内部 API 或未声明网络/文件权限。
