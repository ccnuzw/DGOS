# 03 3D导演台专项技术设计

来源：[功能主文档](../../V2/04-无限画布/01-无限画布与项目.md)。本设计属于 [V5 规划](../../../02-产品与版本/后续版本/V5-规划.md)，不进入 V1 实施或验收。

## 单元契约

| 单元 | 前置条件 | 返回 | 副作用 |
| --- | --- | --- | --- |
| `loadDirectorProject` | 项目可读且引用存在 | 场景与时间线快照 | 无 |
| `createDirectorRunSnapshot` | 机位、资源与能力已校验 | 不可变导出快照 | 记录一次运行批次 |
| `commitCapture` | 导出成功且项目仍可写 | artifact 与新画布节点引用 | 原子提交引用和边 |

## 伪代码

```text
scene = loadDirectorProject(projectRef)                 // B04-25

  connect(directorNode, artifactNode)
commit or rollback
```

## 范围与定位

3D 导演台是画布中的一种高依赖执行/创作节点。节点负责入口、画布连线、状态和项目引用；打开后进入独立的 3D 场景工作区。场景编辑、截图和视频导出可以产生新的 artifact，并回写为画布中的图片/视频节点。删除导演台节点只解除相关连线，不删除已经回写到画布的输出。

依赖顺序为：项目文档与引用闭包 → 节点端口和 artifact → 场景对象与资源 → 相机和时间线 → 导出/渲染能力。任一依赖未配置时，节点显示 `blocked` 及缺失能力，不创建半成品任务。

## 画布节点语义

### 输入与输出

| 方向 | 端口/引用 | 规则 |
| --- | --- | --- |
| 输入 | `panorama.in`（图片/全景 artifact，many） | 普通图片作为背景候选；标记为 `equirectangular` 且尺寸约为 2:1 的图片可作为球形全景；每条来源边保留 `edgeId` 和投影模式 |
| 输出 | `capture.out`（图片 artifact，many） | 当前视角、当前机位、四方位或十二方位截图按批次输出；截图发送到画布创建新图片节点并自动连接 |
| 输出 | `video.out`（视频 artifact，one per export） | 当前活动机位按时间线导出视频；视频节点与导演台保持来源关系，但输出 artifact 独立保留 |

解除全景图连接时，导演台先通知画布移除对应边，再从场景素材中移除该引用；场景其他对象不受影响。连接来源缺失或权限失效时保留引用状态并显示缺失，不伪造可用预览。

### 节点生命周期

导演台节点保存 `directorProject` 引用和当前能力摘要；打开时恢复上次场景、活动机位、时间线位置和面板状态。截图缓存属于设备级临时资产，默认不跨设备同步；发送到画布后转为正式 artifact。场景项目的跨设备同步由 DGOS Project Service 定义，不能用浏览器本地缓存冒充已同步。

## 场景模型

场景至少包含以下稳定实体：

- `SceneObject`：`id`、`kind`（`character|model|primitive|cameraProxy|crowd`）、`name`、`visible`、`locked`、`transform`、`assetRef`、可选 `crowdId` 和角色姿势状态。
- `DirectorCamera`：`id`、`name`、`transform`、`targetMode`、`target`/`targetObjectId`、`fov`、活动状态。相机在场景树和时间线中均可选中。
- `SceneAsset`：模型/角色/全景资源的稳定引用、投影模式、来源和缺失状态。导入的本地模型必须标记设备范围；文件缺失时保留布置参数，重新导入后恢复位置、旋转和缩放。
- `CrowdGroup`：群众成员 ID、组变换、姿势/可见性/锁定等组级属性；群众在时间线上以组轨道保存，不能把每个成员的同一操作写成无法追踪的散落副作用。
- `SceneSettings`：背景色、天空/地面、全景半径与旋转、网格可见性、网格吸附、视口比例和九宫格状态。

对象属性编辑必须支持选择、移动、旋转、缩放、锁定和可见性。网格可以隐藏但不能因此关闭吸附；场景树选择、视口选择、属性面板和时间线选择保持同步。导演视角与机位视角是两个明确的视图模式，不能通过修改场景对象伪造切换。

## 相机、构图与截图

- 视口支持比例框、九宫格、平移/旋转/缩放和方向球；导演视角使用平滑阻尼，机位视角按当前相机快照渲染。
- 机位面板可编辑位置、旋转/注视目标和 FOV，并以当前时间的关键帧值生成截图。截图记录相机 ID、时间、FOV、位置、目标、视口比例和来源模式。
- 截图命令分为“当前视角”“当前机位”“四方位”“十二方位”。每一项生成独立 capture，批次内顺序稳定。
- 发送截图时，以导演台节点右侧为锚点按固定纵向间距创建图片节点；连续发送和批量发送不得重叠。截图节点使用新 artifact，不引用临时 canvas data URL。
- 截图失败、WebGL/模型缺失或导出中止不得清除已有截图记录；错误必须可重试。

## 时间线与关键帧

时间线状态与场景对象分离保存：`durationSeconds`、`fps`、`currentTime`、播放状态、循环状态、轨道和关键帧。基础规则：

1. 角色/模型支持位置、旋转、缩放关键帧；角色额外支持姿势关键帧；相机支持位置、旋转/目标和 FOV；群众属性以组轨道保存。
2. 支持手动添加/删除、自动记录、单帧拖动和对象范围等比例缩放。拖动关键帧时实时预览被拖属性与目标时间其他属性的合成值，松手后一次保存并产生一个撤销单元。
3. 属性轨道可展开速度曲线；进入/离开控制柄可独立调整，双击单柄恢复默认；相邻动画段可选择曲线预设。控制柄超出可视范围时只调整显示，不篡改实际时间值。
4. 关键帧默认按 30 FPS 吸附，播放预览最高 60 FPS；默认循环播放；空格切换播放/暂停；滚轮横移，`Ctrl/Cmd + 滚轮`缩放时间轴。时间线高度可调整并可整体隐藏。
5. 角色和活动机位可在导演视角显示位置轨迹。时间线选择、场景树选择、右侧属性面板和活动机位保持一致。
6. `autoKey` 只影响用户明确修改的可动画属性；关闭后普通属性编辑不得暗中创建关键帧。

## 导出与回写

- 导出必须指定活动机位、时间线版本和输出范围。默认输出为 1280×720、30 FPS、H.264 MP4；具体编码能力由 DGOS Renderer/Worker capability handshake 确认。
- 导出只渲染活动机位可见的 3D 场景，不把导演台界面、场景树、时间线或调试网格写入视频。
- 导出期间冻结播放状态和起始时间，使用独立导出快照逐帧渲染；完成/失败/取消都写入可追踪运行批次，恢复用户原来的播放状态和时间。
- 成功视频回写画布时创建新视频 artifact 和视频节点，携带宽高、时长、FPS、机位和时间线版本元数据，并自动建立 `director -> video` 边。导出视频不依赖导演台节点继续存在。
- 导出失败不产生可见半成品节点；取消不得把中间 Blob 当作完成结果。

## 运行、权限和失败

3D 导演台的模型导入、跨设备同步、截图、视频导出和外部渲染分别检查 DGOS 能力和权限。节点内的“打开导演台”不等于允许上传模型或提交渲染任务；高成本/外部调用必须在运行前由 DGOS Permission Service 确认。场景数据不能保存 API Key、私有文件路径或临时下载 URL。

## 稳定设计分支

- `B04-25`：全景输入边和投影模式在导演台项目中保持稳定引用。
- `B04-26`：场景/机位/时间线导出使用不可变 `DirectorRunSnapshot`，不读取导出过程中的实时编辑状态。
- `B04-27`：截图和视频回写通过新 artifact 与新画布节点完成，批量回写失败时整体回滚。
- `B04-28`：导演台节点删除、能力缺失、模型缺失或导出取消不得删除已完成输出，也不得提交半成品。

## 验收标准

#### AC13 3D 导演台场景、时间线与回写

Given 画布中存在导演台节点、一个可读全景图和可用 3D 能力。

When 用户布置对象和机位、编辑关键帧、执行当前机位/多方位截图或导出视频，并将结果发送回画布。

Then 场景、对象选择、相机、时间线和关键帧在关闭重开后恢复；截图和视频按稳定 artifact 回写并自动连接；导出使用固定机位/时间线快照，失败或取消不产生半成品，删除导演台不删除已回写结果。
