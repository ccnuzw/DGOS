## 目标

创作者能在项目内创建无限画布，放置和编辑资源/配置节点，用连线表达输入关系，并安全保存、导入和导出画布结构。

## 功能边界

包含：画布列表与项目新建/打开、分组/最近使用/回收站入口、文本、图片和上传文件等内容节点，基础输入/输出端口、节点拖拽缩放、选择、连线、分组、点阵视口、小地图、右键创建与选中集上下文命令、撤销重做和结构导入导出。执行节点、历史/资产、表格、画布 Agent、供应商节点和 3D 导演台按后续版本接入。

不包含：AI 任务执行器本身、多人冲突合并和旧项目本地 Blob 存储方案。

## 需求说明

### 用户故事

作为创作者，我希望把素材、提示词和生成配置放在同一张无限画布上，以便观察和复用上下文。

### 业务规则

1. 节点 ID 在项目内稳定，连线只能引用存在的节点；双击连线继续操作不得生成悬空边。
2. 右键创建、上下文浮动工具栏和小地图属于画布交互，不改变项目数据所有权。
3. 分组边界可根据组内内容自适应，但不能遮挡节点端口或改变节点 ID。
4. 删除节点必须同时处理受影响连线；保存失败不能覆盖上一次有效项目。
5. 导入数据必须校验版本和结构，异常数据不得直接写入项目。
6. 画布列表中的分组、最近使用和回收站是项目导航元数据；它们不能改变画布文档中的节点 ID 或引用闭包。
7. 节点选中态必须提供稳定边界；缩放只改变节点尺寸，不能修改节点语义或端口方向。
8. 文本、上传文件和基础输入节点使用统一端口模型；V2 不显示可执行运行按钮。
9. 删除节点、从回收站移除画布和删除 DGOS 文件是不同操作；前两者不得默认物理删除仍被引用的 artifact。
10. 右键命令必须声明作用域、适用节点类型和副作用；整理和基础连接只处理当前选中节点集，不得静默改写未选中节点。
11. 连接命令必须校验端口方向和类型；不兼容时拒绝并说明原因，不得创建悬空边或隐式运行任务。
12. 导出结构包必须剔除 API Key、完整媒体内容、临时运行字段和系统私有路径；模板发布归 V5。
16. 手工连线只接受 `output -> input`；输入输出方向相反、类型不兼容、自连接、重复边和会形成非法环路的连接必须拒绝。
17. “整理连接节点”只移动当前选中节点，按选中子图的拓扑层级和稳定排序布局；不创建、删除或重定向连线，检测到环路时不提交布局变更。
18. “连接下游节点”先展示兼容性预览，再一次性创建目标节点、动态输入端口和连线；不兼容来源必须给出原因，批量操作失败不得留下部分节点或边。
19. 端口具有稳定 `portId`、方向、数据类型、基数和声明顺序；动态输入端口先持久化再建立边，端口删除或重排不得改变既有端口 ID。

### 主流程

1. 从画布列表新建或打开画布，可按分组、最近使用和回收站筛选。
2. 在点阵工作区添加文本、图片或上传文件等内容节点，调整尺寸、位置与分组。
3. 从端口建立经过方向、类型和基数校验的基础连接，选中集可预览整理或连接影响。
4. 使用小地图定位画布，保存项目、关闭并重开；结构导入先解析和预览，再原子提交。
5. 冲突、权限不足或结构不兼容时保留最后有效版本，显示原因并允许刷新或取消。

### 连接手势

连接从节点端口开始，拖动过程中只高亮通过方向、类型、MIME/能力和基数校验的目标端口；从输入端拖动时，系统将边归一为目标输出到当前输入。视频中观察到的“双击连线继续操作”属于产品目标手势，必须复用同一预览与校验管线，不得直接追加未经校验的边；若成熟软件行为或 DGOS 项目/编辑协议另有确认，应新增决策记录再调整语义。

### 异常与边界

- 项目不存在/无权限：展示稳定错误和返回入口。
- 导入版本不兼容：拒绝导入并保留当前画布。
- 保存冲突：提示重新加载或合并，不静默覆盖。
- 端口方向错误、类型不兼容、单值输入已占用、重复边、自连接或非法环路：拒绝本次连接，保留当前图并显示可解释原因。
- “整理连接节点”检测到选中子图环路或保存失败：不改变节点位置，保留原版本并提示用户。
- “连接下游节点”存在部分兼容来源：默认进入预览并要求用户确认“仅连接兼容项”；未确认时不创建目标节点。

### 页面与交互

画布为主工作面，包含画布列表/分组/最近使用/回收站、点阵背景、节点创建菜单、选择与编辑工具、缩放控制、小地图/导航、显示选中数量和适用操作的右键菜单、双击连线续接、节点上下文浮动工具栏、分组自适应和保存/同步状态。V2 基础阶段需支持多类型节点同屏；多维表格、上下文 Agent、Midjourney 等供应商节点和 3D 导演台按各自依赖阶段开放，未配置能力显示禁用原因。V3 起执行节点的媒体与运行字段按动态模型 schema 展示，V2 只保存基础节点配置和端口元数据。

### 节点能力与细节行为

节点定义分为“内容节点、编排节点、执行节点、结果节点”四类。所有节点都使用统一节点外壳：稳定标题和类型标识、选中边界、删除入口、可选运行状态、输入/输出端口、尺寸调整和右键菜单；节点内部字段由节点类型 schema 决定，不能通过前端猜测供应商字段。

| 节点类别 | 首批节点 | 必须支持的细节行为 | 端口/状态要求 |
| --- | --- | --- | --- |
| 内容节点 | 文本/提示词、上传文件/资产、图片/视频/音频引用 | 直接编辑或拖入文件；媒体可预览；图片引用支持裁剪、扩展、遮罩、画笔、缩放和宫格切分等编辑操作，编辑结果生成新 artifact，不覆盖原引用 | 输出端口按实际媒体类型声明；缺失文件显示缺失态，不伪造可读内容 |
| 编排节点 | 分组、提示词组、循环 | 分组边界随成员自适应；分组可作为一个复合来源；循环支持次数、串行/并行、起始序号、批量大小、图片输入和提示词输入开关 | 复合来源保留成员顺序；循环输入开关关闭前必须处理现有连接，不能静默丢失用户数据 |
| 执行节点 | 生成卡片、LLM、ComfyUI/插件、供应商节点、3D 导演台 | 字段按模型/插件 schema 动态显示；可配置平台、模型、提示词、媒体引用、比例、分辨率、质量和 Skill；运行、停止、重试和下游级联可追踪 | 节点状态至少有 `idle`、`blocked`、`queued`、`running`、`done`、`failed`、`stopped`；运行前检查必填端口和能力 |
| 结果节点 | 生成结果/输出 | 按运行批次保留 artifact 列表；支持预览、下载、复制提示词、结果与原始引用对比，并可将结果拖回画布作为稳定引用 | 输出只保存 `artifactId` 和元数据；同一 artifact 不重复写入，最新结果不覆盖历史批次 |

3D 导演台节点的场景、全景输入、对象/机位、时间线、关键帧、截图、导出和回写语义以[3D 导演台专项](../../V5/04-无限画布/03-3D导演台专项-技术设计.md)为准，不在通用节点表中压缩成普通生成卡片字段。

#### 统一输入聚合

执行节点将入边按目标端口 `order`、用户重排顺序和创建顺序稳定聚合。文本/提示词输入可合并为有序文本，媒体输入保持图像、视频、音频和文件类型及编号；连接来源存在时，节点内同义手工输入显示为只读或“以连接为准”，避免运行时出现两套隐含值。任何输入重排只改变边槽位和显示顺序，不改变节点 ID、端口 ID 或 artifact ID。

#### 循环与级联运行

循环节点的次数范围为 1–100；提示词循环使用 1 起始的 `《计数》` 变量，图片循环使用明确的起始序号和批量大小。串行模式按拓扑顺序完成一轮后再进入下一轮；并行模式按 DGOS Worker 声明的并发上限分批执行，不能因前端线程数改变结果顺序。以某执行节点启动“一键运行”时，系统反向收集上游执行节点并按拓扑顺序运行；中途失败停止后续节点，保留已完成结果，并允许从失败节点重试下游链路。停止、失败和重试都必须关联同一 `requestId`/运行批次，不能产生重复任务。

#### 分组与复合来源

图片组、提示词组是可引用的复合来源，不是把成员复制成另一份媒体。将已有图片/提示词节点加入组时，若成员原本直接连接到同一执行节点，系统在一次可撤销事务中把成员边收敛为组边、去重并保持目标端口顺序；组外的其他边不受影响。拆组或移除成员前展示受影响边，用户确认后才恢复直接来源或保留组引用。

#### 选中集与快捷创建

从选中图片或提示词执行“连接下游”时，可先创建一个临时复合来源再接入生成卡片/LLM；复合来源的成员、顺序和端口映射必须出现在预览中。Alt/Option 拖拽复制节点或工作流时，必须生成新节点 ID，并按显式选项决定是否复制内部边；运行状态、任务 ID 和临时引用不随复制带入。

#### 节点运行与结果回写

节点运行前生成不可变运行快照，包含节点配置版本、输入 artifact 引用、端口顺序和模型能力版本。结果到达后按运行批次追加到结果节点，并把最新 artifact 引用同步给合法下游；过期轮询不得覆盖更新的终态。失败保留输入和配置，显示用户可读原因并提供重试；运行按钮不得在一次点击中创建多条等价任务。

#### 工作流导入导出

导出支持“结构 JSON”和“结构 + 允许携带的资源包”两种模式。导出前展示节点数、边数、外部依赖、权限和将被剔除的秘密/私有路径；API Key、DGOS endpoint、完整媒体内容和临时运行字段不得进入包。导入先解析并校验版本、节点类型、端口和资源清单，再为所有节点/边/组成员重映射 ID，将整体左上角平移到释放位置，清空运行态并保留内部连接；任一校验失败时当前画布不变。导入后的资源默认作为新 artifact 引用，不覆盖同名本地文件。

### 领域数据语义

项目文档包含画布导航元数据、节点、连线、视口、分组、节点类型、端口状态、任务引用和媒体引用；大型媒体不直接嵌入 JSON。生成历史和产物索引由 `V1-FR-008` 管理，画布只保存稳定引用。节点显示字段（平台、模型、比例、分辨率、质量、Skill 开关、输出类型）是可版本化配置，不是供应商 endpoint 或秘密。

### 本版本不做

不冻结多人协作冲突算法和移动端触控细节。

### 错误矩阵

| 场景 | 规划错误语义 | 处理要求 |
| --- | --- | --- |
| 项目文档版本冲突 | `version_conflict` | 保留当前已保存版本并提示合并 |

| 保存失败 | `persistence_failed` | 保留旧版本，不显示保存成功 |

## 数据与事务

项目写入以完整文档版本为单位；保存前校验引用闭包，写入失败保留旧版本。

### 涉及数据

V2+ 项目文档、节点、连线、画布视口、插件引用、工作流运行引用和迁移版本；V1 不持有这些数据。

### 约束与事务

项目写入按完整文档版本提交；提交前校验节点/连线/资产引用闭包；失败保留最后有效版本；自动保存需支持并发版本检测。

### 字段读写矩阵

| 数据 | 项目服务 | Canvas 应用 | 插件/节点 |
| --- | --- | --- | --- |
| 项目文档/版本 | 权威读写 | 经 API 读写 | 仅声明范围读写 |
| 节点/连线 | 持久化 | 编辑 | 只写授权节点字段 |
| 秘密/凭据 | 不进入项目 | 不读取 | 不读取 |

### 状态与生命周期

项目：`creating` -> `active` -> `archived`/`deleted`；保存：`dirty` -> `saving` -> `saved`/`conflict`/`failed`；节点运行状态与文档保存状态分离。

### 物理约束与迁移

文档需带 schemaVersion 和单调递增 revision；迁移先验证、再原子写入，保留可恢复旧版本；大媒体只存 artifact 引用。

### 数据所有权

DGOS Project 服务拥有项目文档和版本；Canvas 应用拥有本地交互状态；插件只拥有声明的扩展数据空间。

### 安全与保留

文档按项目权限隔离；禁止写入凭据、完整秘密和不受控本地路径；删除和归档遵循项目保留及恢复策略。

## 验收标准

#### AC01 编辑并恢复画布

Given 项目中存在文本、图片和配置节点及连线。

When 用户移动节点、保存项目并重新打开。

Then 节点、连线、分组和视口恢复一致。

#### AC02 非法导入不破坏当前项目

Given 导入文件版本不兼容或引用不存在的节点。

When 用户执行导入。

Then 导入被拒绝，当前项目保持原样并显示原因。

#### AC03 画布节点与导航交互

Given 项目包含图片、文本和基础输入等 V2 内容节点。

When 用户通过右键菜单创建节点、双击连线继续操作、使用浮动工具栏和小地图导航。

Then 节点、连接、分组和视口保持可编辑，分组边界随内容调整，且不存在悬空连线或不可见节点。

#### AC04 画布导航与节点基础类型

Given 用户拥有多个画布和一个可编辑画布。

When 用户从分组/最近使用/回收站进入画布，并创建文本、图片或上传文件节点。

Then 画布导航状态、节点边界、连接入口、浮动工具栏和点阵视口可用，且不会把节点操作误当成 DGOS 文件删除。

#### AC06 选中集上下文命令

Given 画布中选中了一个或多个节点，且部分节点可能不兼容目标端口。

When 用户执行整理或连接基础内容节点命令。

Then 命令只作用于适用的选中节点，端口不兼容时拒绝连接并说明原因，且不隐式启动任务。

#### AC09 整理连接节点

Given 当前选中节点形成一个包含有向边的子图，且选中集外的节点不得被移动。

When 用户执行“整理连接节点”。

Then 系统按拓扑层级从左到右布局，层内按连接重心、原始位置和稳定 `nodeId` 排序，重复执行得到相同坐标，保持节点尺寸、端口语义和所有连线不变；若检测到环路、固定节点碰撞或保存失败，则原子取消位置变更并说明原因。

#### AC10 连接下游节点

Given 用户选中一个或多个内容节点并选择连接一个兼容的基础目标节点。

When 系统计算输出端口与目标输入端口的兼容关系并提交连接。

Then 方向、类型、MIME/能力、基数和环路约束全部通过后，先创建稳定动态输入端口再创建去重后的边；不兼容来源显示原因，批量失败时目标节点、端口和边均不落盘，且不自动运行任务。

#### AC12 分组复合来源与工作流迁移

Given 用户把多个内容节点分组，或导出/导入包含分组、动态端口和内部连线的工作流。

When 用户确认分组接管连接，或将工作流释放到另一画布。

Then 分组接管和拆分均为可撤销事务；导出包不含秘密和临时运行字段，导入会校验版本、重映射全部 ID、平移布局并恢复内部边，失败时原画布保持不变。

历史 `AC05/AC11` 的节点执行方向移至 V3，`AC07/AC08` 的表格、资产和 Agent 方向移至 V4，`AC13` 的导演台方向移至 V5；正式新 AC 编号均待相应版本门禁分配，旧号不复用。

### 回归要求

- 节点拖拽、缩放、选择和连线不能导致布局抖动或数据丢失。
- 画布保存不得把大媒体转成无界 Base64。
- 点阵背景和小地图不能遮挡节点端口、状态或底部编辑工具；不同窗口尺寸和系统缩放下仍需保持可操作。
- V2 不执行节点运行；运行能力的回归要求由 V3 独立规格维护。
