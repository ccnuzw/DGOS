# 02 桌面与应用工作区：技术设计

来源：[功能主文档](01-桌面与应用工作区.md)。需求、接口、数据和验收细节以主文档及公共契约为准。

## 单元契约

| 函数/服务 | 前置条件 | 返回/后置条件 | 副作用 |
| --- | --- | --- | --- |
| `launchApp(subject, appId, entrypoint)` | 应用已安装、manifest/API 版本兼容、启动权限允许 | 返回窗口引用和脱敏运行时上下文；失败不创建可用窗口 | 创建窗口、写入启动审计 |
| `writeSettings(subject, domain, patch, baseVersion)` | 设置域已注册；patch 通过 schema；主体具有设置权限 | 成功返回新 `settingsVersion`、有效值和 `restartRequired`；冲突不覆盖新值 | 原子写入设置域、发布上下文事件 |
| `publishContext(appId, subject)` | 应用拥有运行时上下文读取权限 | 返回不含秘密的 `SystemContextSnapshot`，`contextVersion` 单调递增 | 发布上下文变更事件 |
| `checkCapability(subject, appId, capability, scope)` | 请求带有 requestId；capability 已注册 | 返回 `allow/ask/deny`、原因、策略版本和审计引用 | 写入脱敏授权审计 |

## 伪代码

```text
function launchApp(subject, appId, entrypoint): Result<WindowRef, Error> {
  REQUIRE subject is valid
  REQUIRE appId is registered

  // B01-01
  install = appInstallStore.get(appId)
  if install is missing or install.state != "active":
    RETURN Err("app_unavailable", requestId)

  // B01-02
  if !manifestCompatible(install.manifest) or !verifyPackage(install.package):
    RETURN Err("app_package_invalid", requestId)

  // B01-03
  decision = permission.check(subject, appId, "dgos.app.launch", entrypoint.scope)
  if decision == "deny":
    audit.redacted(requestId, "launch_denied")
    RETURN Err("permission_denied", requestId)
  if decision == "ask":
    RETURN Err("confirmation_required", requestId)

  // B01-04
  context = contextService.snapshot(subject, appId)
  window = windowHost.create(entrypoint, context)
  audit.redacted(requestId, "launch_succeeded", appId, window.id)
  RETURN Ok(window)
}

function writeSettings(subject, domain, patch, baseVersion): Result<SettingsSnapshot, Error> {
  REQUIRE domain is registered
  REQUIRE patch contains no secret value; secret fields use SecretRef

  // B01-05
  decision = permission.check(subject, "dgos.system.settings", "dgos.settings.write", domain)
  if decision != "allow":
    RETURN Err("permission_denied", requestId)

  // B01-06
  validated = settingsSchema.validate(domain, patch)
  if !validated.ok:
    RETURN Err("invalid_settings", requestId)

  BEGIN TRANSACTION
    current = settingsStore.read(domain)
    // B01-07
    if current.version != baseVersion:
      ROLLBACK
      RETURN Err("settings_version_conflict", requestId)
    next = settingsStore.apply(domain, validated.value, baseVersion)
    settingsStore.commit(next)
    // B01-08
    contextService.publish(next, redacted=true)
    audit.redacted(requestId, "settings_updated", domain, next.version)
  COMMIT OR ROLLBACK

  RETURN Ok(next)
}

function checkCapabilityBeforeSideEffect(subject, appId, capability, scope): Decision {
  // B01-09
  decision = permission.evaluate(subject, appId, capability, scope)
  if decision == "deny":
    audit.redacted(requestId, "capability_denied")
  return decision
}
```

## 约束备注

- 权限服务的实时判定是最终边界；manifest、前端按钮和缓存授权不能替代执行前检查。
- `SystemContextSnapshot`、审计和错误响应不得包含 API Key、Token、Cookie、绝对路径或完整代理凭据。
- 设置域写入必须使用版本校验和原子提交；代理设置保存成功但服务未重启时，不能宣称有效路由已经切换。
- V1 只恢复 DGOS 自有桌面/窗口工作区上下文，不创建或修改 V2 `Project` 文档；项目读写由 V2 功能单独验收。
