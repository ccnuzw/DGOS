# V1 功能规格索引

V1 登记 15 个可独立规划和验收的功能。首发交付按平台控制面、系统服务和 DGOS AI 工作台参考 APP 管理；高风险功能另有技术设计；实现状态统一查看[V1 实现状态](../../02-产品与版本/当前版本/V1-实现状态.md)。

## 首发范围分层

| 层级 | 功能 |
| --- | --- |
| V1 独立系统平台最小闭环 | `V1-FR-001`、`V1-FR-002`、`V1-FR-003`、`V1-FR-009`；FR-005/007 由 DGOS AI 工作台和平台服务按冻结范围交付 |
| V2–V5 创作应用与扩展能力 | V2 `V1-FR-004` 基础；V3 FR-005 画布工作流；V4 FR-008 与 FR-005/007 结构化能力；V5 `V1-FR-006` 与 FR-004 3D 专项 |

## 依赖主链路

```text
FR-001 -> FR-002/003 -> FR-007 -> FR-005（线性任务）
V2: FR-004 基础项目与画布
V3: FR-004 + FR-005 画布工作流
V4: FR-004 + FR-005/007 高级子集 + FR-008
V5: FR-004 3D 专项 + FR-006 插件/模板
```

身份与治理：`V1-FR-010` -> `V1-FR-011/012/013` -> `V1-FR-014`
