# 05 多模态 AI 任务工作流：技术设计

来源：[功能主文档](01-多模态AI任务工作流.md)。

## 单元契约

| 函数 | 前置条件 | 返回 | 副作用 |
| --- | --- | --- | --- |
| `resolveTarget(intent, inputs)` | 模型目录可读 | descriptor | 无 |
| `submitTask(task)` | descriptor 可执行 | taskId/status | 创建一次 AI 任务 |
| `advanceTask(taskId)` | taskId 属于当前请求 | 状态/产物 | 查询任务 |
| `previewArtifact(artifactId)` | 任务 succeeded 且 artifact 可读 | 预览数据 | 任务工作区读取产物 |
| `materializeArtifacts(outputs)`（V3） | 任务 succeeded、项目可写 | 画布产物引用 | 写项目/画布 |

## 伪代码

```text
submitTask(task):
  REQUIRE task.requestId is stable
  // B5-01
  resolve descriptor and validate dynamic params/inputs
  IF unavailable: RETURN Err(MODEL_UNAVAILABLE)
  // B5-02
  submit DGOS aiTask once
  WHILE status == pending:
    query same taskId
  // B5-03
  IF succeeded:
    read artifactId and expose it to the task workspace preview
  ELSE:
    preserve terminal error and do not create a result node

// V3 only
materializeArtifacts(outputs):
  REQUIRE project and canvas contracts are available
  write artifact references and node state idempotently
```

`dgos.agent.*` 执行记录和 `dgos.aiTask.*` 媒体任务必须分开；供应商任务标识不能替代 DGOS taskId。
