# 07 模型平台与工作流配置：技术设计

来源：[功能主文档](01-模型平台与工作流配置.md)。功能需求、接口、数据和验收口径以主文档及公共契约为准。

V1 技术设计覆盖 ProviderConfig 验证、ProtocolAdapterRegistry、ProviderCapabilityDescriptor、CapabilityProtocolRegistry、Model Profile 解析和 ModelCatalog 刷新；`setWorkflowState` 与 B07-05 属于 V3/V4 工作流配置，不进入 V1 首发门禁。

## 协议注册与解释边界

`ProtocolAdapterRegistry` 管理连接协议；`CapabilityProtocolRegistry` 管理 DGOS `dgos-capability/v1` 能力协议。二者通过 Provider/模型上下文关联，但不能互相替代：连接协议负责安全连接和目录读取，能力协议负责 Intent 到供应商 operation 的声明式映射，Model Profile 负责真实模型名到能力 workflow 的覆盖。验证或更新失败必须把 Provider 标为 `disabled/error`，阻止新任务；已提交任务仍按自身 taskId 收敛，目录和策略历史保留。

| 组件 | 输入 | 输出 | 禁止事项 |
| --- | --- | --- | --- |
| `ProtocolAdapterRegistry` | protocolType、ProviderConfig、秘密引用 | 连接状态、目录、连接层 descriptor | 不根据供应商名称猜测能力；不把秘密交给 APP |
| `CapabilityProtocolRegistry` | protocol JSON、文档版本、Provider/模型上下文 | 校验后的 operations/workflows/Profile/UI/asset 描述 | 不执行脚本、eval、Shell、任意 URL 拼接 |
| `ModelProfileResolver` | 真实模型名、兼容别名、Intent | capabilities、workflow、defaults、limits、uiSchemas、assets | 未命中 Profile 不得进入任务选择器 |
| `DeclarativeOperationExecutor` | 已校验 operation、输入快照、权限上下文 | 脱敏响应、任务状态、Artifact | 不接受运行时新增字段、未声明重试或未声明下载 |

协议解释器在执行前完成 schema、路径、requestMode、selector、引用参数、状态枚举和素材绑定校验；执行时只解析 `$map`、`$concat`、`$merge`、`$coalesce`、`$cardinality`、`$dataUrlBase64`、`$keyValue` 与 `omitEmpty`。operation 的 `path` 必须是注册连接协议下的真实相对路径，download 若需鉴权则强制 `responseMode=binary`。submit 不默认重试，只有文档明确幂等时才读取 retry 配置。

## 单元契约

| 函数 | 前置条件 | 返回 | 副作用 |
| --- | --- | --- | --- |
| `saveProviderDraft` | 用户有配置权限，非秘密字段格式合法 | draft 引用 | 写入 DGOS Config/Secret 服务 |
| `validateProvider` | draft 存在且未过期 | active/error 状态、脱敏 descriptor 摘要 | 访问 DGOS provider adapter；不返回秘密，不刷新模型目录 |
| `refreshProviderModels` | Provider 已处于 active 且有有效验证结果 | 本次目录快照、刷新状态 | 调用 Adapter 模型目录接口；保留用户策略，不自动启用模型 |
| `resolveProtocolAdapter` | `protocolType` 已注册且配置 schema 合法 | 适配器版本和能力 descriptor | 读取注册表；不读取明文秘密 |
| `validateCapabilityProtocol` | protocol JSON 已提交且 schemaVersion 受支持 | canonical protocol、校验问题和 descriptor 摘要 | 不执行 operation；拒绝脚本和未知映射原语 |
| `resolveModelProfile` | 真实模型名已由目录返回 | Profile、Intent/workflow、UI/限制/素材描述 | 未命中 Profile 返回 `model_profile_missing` |
| `executeDeclarativeWorkflow` | workflow 通过校验且模型/权限可用 | submit/query/download/upload 任务结果 | 只执行已声明 operation；结果必须形成统一 Artifact 或结构化错误 |
| `setWorkflowState`（V3/V4） | 配置属于当前用户且 schema 合法 | active/disabled 状态 | 更新 AI 应用或工作流启停 |

## 伪代码

```text
validateProvider(providerId, requestId):
  REQUIRE hasPermission("provider.write")
  draft = config.read(providerId)
  // B07-01
  IF draft is missing OR draft.expired:
    RETURN Err("config_not_found")
  // B07-02
  adapter = resolveProtocolAdapter(draft.protocolType)        // V1: openai-compatible
  descriptor = adapter.describeCapabilities(draft, requestId)
  result = adapter.validate(providerId, requestId)             // ASYNC; secret stays in DGOS Secret Service
  // B07-03
  IF result.ok is false:
    // B07-03
    config.transition(providerId, "disabled", result.redactedError)
    RETURN Err("provider_unavailable")
  config.transition(providerId, "active", descriptor.summary)
  RETURN Ok(redact({provider, descriptor}))

refreshProviderModels(providerId, requestId):
  REQUIRE hasPermission("provider.write")
  provider = config.read(providerId)
  IF provider.validationState != "active":
    RETURN Err("provider_not_validated")
  catalog = adapter.listModels(providerId, requestId)
  policies = policy.read(providerId)
  catalog = mergeCatalogKeepingPolicies(catalog, policies)
  markMissingModelsStale(catalog, policies)
  RETURN Ok(redact(catalog))

validateCapabilityProtocol(protocol, providerId, requestId):
  REQUIRE hasPermission("provider.protocol.write")
  canonical = schemaValidate(protocol, "dgos-capability/v1")
  REQUIRE canonical.executor.type == "declarative"
  REQUIRE noForbiddenConstructs(canonical)
  REQUIRE operationsHaveRelativePathsAndModes(canonical.operations)
  REQUIRE workflowsReferenceExistingOperations(canonical.workflows)
  REQUIRE asyncWorkflowsDeclareSubmitQueryAndResult(canonical.workflows)
  REQUIRE modelProfilesCoverDeclaredIntents(canonical.modelProfiles, canonical.workflows)
  REQUIRE assetsBoundToUploads(canonical.workflows, canonical.assets)
  RETURN Ok(canonical)

executeDeclarativeWorkflow(task, profile, intent):
  workflow = profile.workflows[intent]
  submit = executeOperation(workflow.submit, task.inputSnapshot)
  task.bindProviderTaskId(submit.taskId)
  IF workflow.poll exists:
    LOOP until timeout:
      snapshot = executeOperation(workflow.poll.operation, task.providerTaskId)
      IF snapshot.status in workflow.poll.status.failure: RETURN Err(redact(snapshot.error))
      IF snapshot.status in workflow.poll.status.success: BREAK
      wait(workflow.poll.intervalMs)
  result = resolveDeclaredResult(workflow.result, snapshot)
  IF workflow.download exists AND result.requiresDownload:
    result = executeOperation(workflow.download, task.providerTaskId, responseMode="binary")
  RETURN persistArtifact(result)

// V3/V4 only
setWorkflowState(workflowId, desiredState):
  REQUIRE desiredState in {"active", "disabled"}
  // B07-05
  IF not owns(workflowId):
    RETURN Err("permission_denied")
  config.transition(workflowId, desiredState)
  RETURN Ok()
```

## 约束备注

秘密只能由 DGOS Secret Service 保存和脱敏；任何未映射分支不能进入 Ready。供应商列表、Base URL 和模型名不得写死在 DGOS 包内。`openai-compatible` 是 V1 首发连接协议类型，不等于固定供应商；后续连接协议通过注册新的 adapter，能力协议通过注册新的版本化声明式 schema、operation 和错误映射接入。能力协议不得成为任意远程代码执行入口；所有路径、状态、结果和素材上传均需在注册与执行前校验。
