## 目标

记录 DGOS 发起的模型调用用量，提供可配置软/硬额度、调用前预检与预留、任务终态结算和管理员查询；V1 不实现支付或计费。

## 功能边界

记录 DGOS 发起的模型调用用量，提供可配置的软/硬额度、调用前预检与预留、任务终态结算和管理员查询。V1 用量是治理和透明度能力，不是计费、支付、发票、供应商账单对账或用户余额系统。

计量主体为 DGOS 主体、Provider account、ProviderConfig、模型和 AI Task；FR-005 拥有任务状态，FR-007 拥有模型资格和 ProviderConfig，FR-012 拥有上游账号，FR-015 消费不可变调用事实并维护额度预留/汇总。

## 需求说明

### 业务规则

1. 每次上游调用使用稳定 `taskId + attemptId` 作为去重键；重试 attempt 单独记录，不能重复结算同一 attempt。
2. 提交前按当前主体、账号、模型和策略版本执行 quota preflight；硬额度不足时不得调用上游，软额度仅告警并按策略允许/拒绝。
3. 异步任务先创建额度 reservation；成功、失败、取消或超时终态均须释放或结算 reservation，终态唯一且可重放修复。
4. 计量值按可得数据逐级记录：调用次数必需；token 仅在上游可信提供且适配器校验后记录；金额估算必须标记 estimate，不得称实际费用。
5. Provider 返回的 usage 可能缺失或不可信；缺失时记录 `usage_status=unavailable`，不得猜测 token 或费用。
6. 额度策略按主体/部署和时间窗版本化；策略变更不追溯改写历史 usage，窗口切换按服务端统一时钟处理。
7. 用户不可通过并发提交超额绕过硬限额；预留必须原子比较并更新。重复 requestId 返回原 reservation/task 关联。
8. 查询与汇总受主体权限限制；普通用户只看自身授权范围，管理员可按策略查看部署范围；响应不包含 Provider 凭据或完整 prompt。

### 前置依赖与执行边界

前置：主体与账号有效、FR-007 提供可用模型目标、FR-005 已完成输入校验、Quota 服务可用。`preflight/reserve -> submit task -> collect provider usage -> settle/release -> aggregate`。FR-005 在调用前取得 reservation reference；任务终态事件触发唯一结算。

状态：reservation `reserved/settled/released/expired/reconciliation_required`；usage `pending/final/unavailable/estimated`。错误：`quota_exceeded`、`quota_unavailable`、`reservation_conflict`、`usage_unavailable`。Quota 服务不可用时 V1 默认 fail closed，除非管理员显式选择有上限的 fail-open 策略并审计。

### 主流程

`preflight/reserve -> submit task -> collect provider usage -> settle/release -> aggregate`。FR-005 在调用前取得 reservation reference；任务终态事件触发唯一结算。

### 异常与边界

硬额度不足返回 `quota_exceeded`；Quota 服务不可用默认 fail closed；Provider usage 缺失记录 unavailable，不猜测 token 或费用。

### 页面与交互

用户查看自身额度/用量和告警；管理员按授权范围查看策略和汇总；页面不显示完整 prompt、凭据或上游原始响应。

### 领域数据语义

`UsageEvent`：usageEventId、subjectRef、providerAccountId、providerConfigId、modelRef、taskId、attemptId、operation、input/output/total tokens（可空）、unit、estimatedCost（可空且带估算标志）、occurredAt、usageStatus、sourceDigest。`QuotaPolicy`：scope、window、hard/soft limit、metric、version、effectiveAt。`QuotaReservation`：reservationId、requestId、taskId、reservedAmount、state、expiresAt。`UsageAggregate` 可重建，不替代事件事实。

Task 服务拥有任务事实；FR-015 拥有用量事件、预留、策略和汇总。保留/聚合周期待数据治理 ADR 冻结；删除明细必须服从审计、隐私和调查保留边界。

### 本版本不做

不实现支付、计费、发票、供应商账单对账或用户余额。

## 数据与事务

### 涉及数据

`UsageEvent`、`QuotaPolicy`、`QuotaReservation`、`UsageAggregate`、`AuditEvent`。

### 约束与事务

预留与额度比较原子提交；任务终态与结算使用 taskId/attemptId 去重；汇总可从事件重建。

### 字段读写矩阵

| 数据 | Usage/Quota | AI Task/Provider | 用户/管理员 |
| --- | --- | --- | --- |
| UsageEvent | 写入/汇总 | 提供 task/usage 事实 | 授权查询 |
| QuotaReservation | 创建/结算 | 引用 reservation | 查询状态 |
| QuotaPolicy | 管理 | 消费版本 | 管理员读写 |

### 状态与生命周期

Reservation `reserved -> settled/released/expired/reconciliation_required`；Usage `pending -> final/unavailable/estimated`。

### 物理约束与迁移

taskId+attemptId 唯一；策略和汇总版本化；窗口和单位由 ADR 冻结。

### 数据所有权

FR-015 拥有用量事件、预留、策略和汇总；Task 服务拥有任务终态；Provider 服务提供账号/模型引用。

### 安全与保留

不保存完整 prompt、凭据或上游 body；查询按主体/管理员范围过滤；保留期由数据治理 ADR 冻结。

## 验收标准

#### AC01 硬额度预检

Given 主体、Provider account、模型和 quota policy 均有效。

When 当前窗口剩余额度不足时提交任务。

Then 返回 `quota_exceeded`，不创建上游 attempt、不产生 Provider 调用；旧任务不受影响。

#### AC02 并发预留

Given 多个请求竞争最后额度。

When 并发提交任务并执行额度预留。

Then 原子预留使总量不超过硬限额；返回每个请求的预留结果，失败请求不留下 reservation、不创建任务且不产生 Provider 调用。

#### AC03 终态结算

Given 任务进入成功、失败、取消或超时终态。

When 终态事件被重复投递或重放。

Then reservation 仅结算或释放一次；失败或重复的 `taskId + attemptId` 重放返回 settlementStatus、usageEventId 和 reservationId，查询确认仅有一条 usage event 记录且 reservation 状态未被重复修改。失败或重复投递时不得：创建新 usage event、修改已结算的 reservation、重复计量额度、产生第二次 Provider 调用、写入重复审计记录。

#### AC04 缺失/估算数据

Given Provider 未提供可信 token usage。

When 任务完成并结算用量。

Then 记录 unavailable 或显式 estimated 状态，不伪造实测数据；请求仍按 Task 终态收敛。

#### AC05 权限隔离

Given 主体查询用量或管理员修改额度。

When 请求超出主体或管理员授权范围。

Then 返回范围内汇总；无权请求不泄露他人用量且不改变策略。

| AC | Given / When | Then 与无副作用断言 |
| --- | --- | --- |
| AC01 硬额度预检 | 当前窗口剩余额度不足时提交任务 | 返回 `quota_exceeded`，不创建上游 attempt、不产生 Provider 调用；旧任务不受影响 |
| AC02 并发预留 | 多个并发请求竞争最后额度 | 原子预留使总量不超过硬限额；失败请求不留下 reservation 或任务副作用 |
| AC03 终态结算 | 任务成功、失败、取消或超时 | reservation 仅结算/释放一次；`taskId + attemptId` 重放不重复计量 |
| AC04 缺失/估算数据 | Provider 未提供可信 token usage | 记录 unavailable 或显式 estimated 状态，不伪造实测数据；请求仍按 Task 终态收敛 |
| AC05 权限隔离 | 主体查询用量或管理员修改额度 | 返回范围内汇总；无权请求不泄露他人用量且不改变策略 |
