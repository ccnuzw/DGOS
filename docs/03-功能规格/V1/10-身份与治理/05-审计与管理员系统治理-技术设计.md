# 审计与管理员系统治理：技术设计

来源：[功能主文档](05-审计与管理员系统治理.md)，D033/D035、ADR-0005/0006。V1无法务保留例外、支付或WORM业务。

## 单元契约

| 单元 | 前置条件 | 返回/后置条件 | 副作用 |
| --- | --- | --- | --- |
| commitAuditedChange(tx) | 授权/版本有效，outbox可写 | 业务与eventId同时可见 | 同事务状态/outbox |
| queryAudit(filter, subject) | audit.read与所属范围 | 脱敏分页，并记录查询审计 | 追加查询事件，不改历史 |
| updatePolicy(baseVersion) | 新鲜认证、权限、版本 | 新版本或冲突 | 策略与审计同事务 |
| sweep(previewDigest) | 预览未失效、范围/期限允许 | 可恢复checkpoint与计数 | 只删到期且无引用数据 |

## 伪代码

```text
commitChange(input): Result<Event>
  // B14-01
  BEGIN TRANSACTION; recheck authority; update domain state; append audit/outbox
  // B14-03
  if outbox unavailable: ROLLBACK; return audit_unavailable
  COMMIT; publisher retries by unique eventId, not business mutation
query(input): Result<Page>
  // B14-02
  restrict actor/time/cursor; redact fields; append query audit before successful disclosure
updatePolicy(input): Result<Policy>
  // B14-05
  BEGIN TRANSACTION; compare baseVersion; conflict => ROLLBACK
  write policy + outbox; COMMIT OR ROLLBACK
sweep(input): Result<Job>
  // B14-04
  verify preview owner/digest/policy version and approved cutoff
  BEGIN TRANSACTION; claim batch; recheck category age, ownership and live references
  delete eligible records; persist checkpoint + audit/outbox; COMMIT OR ROLLBACK
  retry from committed checkpoint; failed audit cannot follow an already committed delete
```

## 约束备注

30天分别从缓存终态/安装失败/会话撤销起算，审计180天从事件创建起算；Task/Artifact显式删除并重算引用，不因到期清理误删。预览不是永久删除许可，实际删除前再次判断。审计只追加；依法定期限受控清理不等于普通API可改历史。迁移增量且删除批次可停可重入；外部对象删除用可恢复工作项/墓碑，失败保留状态，禁止先删对象再补审计。资产映射见[AC资产核对](../V1-AC资产核对-2026-10-02.md)。
