# 上游账号连接测试：技术设计

来源：[功能主文档](04-上游账号连接测试.md)，ADR-0007。诊断不等于validate，不刷新模型、不提交AI任务。

## 单元契约

| 单元 | 前置条件 | 返回/后置条件 | 副作用 |
| --- | --- | --- | --- |
| enqueueTest(account/config, requestId) | 所有权、版本、协议、出站策略通过 | queued记录及审计；重放同testId | DB提交，尚无外部调用 |
| probe(claim) | 有效租约/凭据句柄/已发布探测模板 | 脱敏分类与唯一终态 | 受控网络请求 |
| getTest(testId, subject) | 所属范围有权 | 脱敏快照 | 不改变测试或目录 |
| cancel/expire(testId) | 所属范围且未终态 | cancel_requested后可确认终态 | 取消信号、停止后续探测 |

## 伪代码

```text
enqueue(input): Result<Test>
  // B13-01
  REQUIRE current owner/config/protocol authorization
  BEGIN TRANSACTION; unique scoped request; insert queued + outbox; COMMIT OR ROLLBACK
probe(claim): Result<Diagnostic>
  // B13-03
  validate all DNS addresses and pin transport; verify TLS/host/port/redirect policy
  obtain purpose-bound secret handle only after egress policy permits
  // B13-02
  ASYNC execute declared safe probe with bounded response/time budgets
  classify/redact response; conditional terminal write + outbox; never update model catalog
recoverOrCancel(test): Result<Test>
  // B13-04
  heartbeat renews current lease; lose lease => stop IO and forbid terminal commit
  poll cancellation across instances; abort downstream, then confirm cancelled
  on deadline => timed_out; classify TLS/auth/network distinctly
  uncertain external non-idempotent outcome => no blind retry
```

## 约束备注

复用已有pinned transport，不用“已pinning”代替完整网络安全证据。独立worker接线由Lead整合；租约owner/version与终态竞争必须数据库兜底。结果不暴露SecretRef、内部地址、上游body；query/events同样校验所属主体。实际资产及命令见[AC资产核对](../V1-AC资产核对-2026-10-02.md)。
