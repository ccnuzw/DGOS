## 目标

为指定 ProviderAccount/ProviderConfig 执行受控连通性诊断，区分网络、地址、鉴权、协议和权限问题，并给出可恢复的诊断状态。

## 功能边界

为指定 ProviderAccount/ProviderConfig 执行受控连通性诊断，区分网络、地址、鉴权、协议和权限问题，并给出可恢复的诊断状态。测试由 DGOS Adapter 执行，不把凭据交给前端或 APP。

连接测试不等于 ProviderConfig validate，不刷新模型目录，不启用模型，不创建 AI Task，不证明所有模型/能力可用。模型发现仍必须由用户显式执行 `FR-007 models/refresh`。

## 需求说明

### 业务规则

1. 测试主体必须拥有账号、配置和 `provider.connection_test` 权限；每次测试使用 requestId、account/config version 和 protocol version 快照。
2. 测试只调用适配器声明的安全探测请求；禁止任意 URL、重定向到私网、协议脚本或用户指定任意 path。
3. DNS/IP 解析、重定向、端口和 TLS 校验遵循 DGOS 出站网络策略，阻止 localhost、link-local、私网和云元数据地址，除非部署管理员明确配置允许的内部目标。
4. API Key/Token 通过短时 SecretRef 句柄注入适配器，永不进入请求响应、日志、错误消息、审计或测试证据。
5. 测试结果为诊断快照而非永久健康承诺；成功须限定 protocol、endpoint 指纹、账号版本和测试时间。
6. 同一 requestId 重试返回同一测试记录；并发测试按 account/config 版本限流，不相互覆盖终态。
7. 测试失败不得自动停用或覆盖现有模型目录；FR-007 validate 的 active/error 决策仍由独立验证流程完成。

### 前置依赖与执行边界

前置：账号 active、凭据可用、Adapter 已发布、目标通过出站策略。创建 queued 测试 -> 建立受控连接 -> 执行最小鉴权/协议探测 -> 输出分类诊断和耗时 -> 保存脱敏终态。

状态：`queued`、`running`、`succeeded`、`failed`、`timed_out`、`cancelled`。分类：`network_unreachable`、`tls_invalid`、`endpoint_invalid`、`authentication_failed`、`rate_limited`、`protocol_mismatch`、`upstream_unavailable`、`policy_blocked`。不得把原始上游 body 直接返回。

### 主流程

创建 queued 测试 -> 建立受控连接 -> 执行最小鉴权/协议探测 -> 输出分类诊断和耗时 -> 保存脱敏终态。

### 异常与边界

网络、TLS、鉴权、协议和策略失败均只返回分类摘要，不返回上游原始 body；测试失败不自动停用配置或刷新模型目录。

### 页面与交互

连接测试入口显示 testId、运行中/成功/失败/超时状态、分类原因和重试入口，不显示凭据或内部地址。

### 领域数据语义

`ConnectionTest` 保存账号/配置版本、protocolVersion、状态、分类、耗时和审计引用；不保存凭据、完整 URL query 或上游响应。

### 本版本不做

不提供供应商模型目录刷新、AI Task 提交、Provider 企业账号注册或任意 URL 调试器。

## 数据与事务

### 涉及数据

`ConnectionTest`、`CapabilityProbe`、`ProviderAccount` 引用、脱敏 `AuditEvent`。

### 约束与事务

测试记录先于外部调用进入 queued；终态只写一次；取消/超时通过租约停止后续探测。

### 字段读写矩阵

| 数据 | Provider Adapter | 管理应用 | Audit |
| --- | --- | --- | --- |
| 测试配置 | 最小读取 | 创建/查询脱敏 | 摘要 |
| 凭据 | 短时句柄 | 不可读 | 不可读 |
| 测试状态 | 写入 | 查询/取消 | 结果摘要 |

### 状态与生命周期

`queued -> running -> succeeded/failed/timed_out/cancelled`；分类状态与运行状态分离。

### 物理约束与迁移

testId、requestId 和账号版本组合唯一；测试结果不得保存 Secret 或完整上游响应。物理约束和 checkpoint 遵循 ADR-0006，ProviderEgress、DNS/IP、TLS 和重定向规则遵循 ADR-0007；当前仍无 migration 或运行证据。

### 数据所有权

Provider Test 服务拥有测试记录；Adapter 只执行探测；Secret 服务拥有凭据。

### 安全与保留

阻止私网、link-local、云元数据和越界重定向；仅保留脱敏诊断和最小 endpoint 指纹。

## 验收标准

#### AC01–AC04 上游账号连接测试

Given active Provider account、已发布 Adapter 和允许的出站策略。

When 启动连接探测、查询、取消或注入网络/鉴权/协议失败。

Then 返回脱敏 test 状态和稳定分类；失败、超时或取消不刷新模型目录、不创建 AI Task。

| AC | Given / When | Then 与无副作用断言 |
| --- | --- | --- |
| AC01 成功诊断 | 有权主体对 active 账号启动探测且上游可达 | 返回 testId、protocol/config 版本、耗时与成功分类；不刷新目录、不创建 AI Task |
| AC02 失败分类 | 上游返回鉴权、限流、网络或协议错误 | 返回稳定分类和脱敏摘要；不包含上游响应秘密，不覆盖模型目录和账号配置 |
| AC03 SSRF 与权限边界 | 目标解析到禁止网段、跳转越界或主体无权 | 在外部请求前拒绝并审计，不发生网络副作用，不泄露目标内部地址 |
| AC04 超时/取消 | 测试达到时限或用户取消 | 终态为 timed_out/cancelled；停止后续请求，保留可查询记录，不伪造成功 |

## 安全、观测与恢复

设定连接/读取超时、有限重试和并发预算；默认一次请求且不自动重试非幂等探测。观测 requestId、testId、协议版本、状态、延迟和错误分类，不保存完整 endpoint query、Authorization 或 body。失败后用户修正账号或配置并显式重新测试。

## 实现与验证

当前无连接测试运行时、测试资产或运行证据；探测矩阵、出站 allowlist 和 operation schema 已由 ADR-0007 冻结设计基线，仍待实现和安全测试验证。
