# 管理员登录与会话：技术设计

来源：[功能主文档](01-管理员登录与会话.md)。按D029/D034、ADR-0005–0007实施，字段以OpenAPI为准；本设计不声明已实现。

## 单元契约

| 单元 | 前置条件 | 返回/后置条件 | 副作用 |
| --- | --- | --- | --- |
| bootstrap(deployment, requestId) | 受控首启、无既有管理员 | 唯一受控主体与会话；重放原结果 | 主体/Session/outbox同事务 |
| login(factor, source) | 认证与共享限速可用 | 脱敏会话或不可枚举失败 | 成功创建会话，失败只记录安全审计 |
| renew/revoke(session, version) | 所属主体及权限有效 | 版本化会话；撤销优先 | Session与outbox同事务 |
| requireFreshAuthorization(target) | 当前Session、资源权限、认证新鲜度 | 允许或step_up_required；失败无目标写入 | 仅经领域事务提交 |

## 伪代码

```text
bootstrap(input): Result<Session>
  // B10-01
  REQUIRE controlled local bootstrap and valid requestId
  BEGIN TRANSACTION; lock deployment bootstrap key
  if initialized: return authorized replay or conflict; never create second subject
  create principal + independent host session + audit outbox; COMMIT OR ROLLBACK
login(input): Result<Session>
  // B10-02
  REQUIRE secret backend and shared limiter available
  check rate window; verify factor without exposing subject existence
  if rejected: return authentication_failed/rate_limited without session
  BEGIN TRANSACTION; create session and audit outbox; COMMIT OR ROLLBACK
changeSession(input): Result<Session>
  // B10-03
  BEGIN TRANSACTION; lock owned session; check current version/state
  if revoked/expired: ROLLBACK; return session_revoked/session_expired
  update version/state and audit; COMMIT OR ROLLBACK
authorizeHighRisk(input): Decision
  // B10-04
  recheck current session, resource scope, capability and authentication freshness
  if stale: return step_up_required; do not call target handler
  return permit for this version/target only
```

## 约束备注

复用已实现共享限速；不强制引入认证缓存，但任何实例都须看到撤销。Session不得以通配scope代替资源授权。生产缺受控Secret backend时启动/认证失败封闭，不能回退内存。恢复只撤销Session/轮换绑定，不删除用户数据；桌面/Web同主体、独立Session。迁移只增量，历史SQL不改。具体资产、命令及等级见[AC资产核对](../V1-AC资产核对-2026-10-02.md)。
