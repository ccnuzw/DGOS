# 01 系统智能助手与快捷指令

> 范围说明：V1 交付 DGOS 官方助手应用、统一动作目录、系统级自然语言查询/导航，以及覆盖大部分已有公开契约的系统设置和应用配置动作。写入、删除、权限/隐私、秘密/凭据、网络出口、不可逆和外部副作用动作按风险确认；项目、画布、资产和未具备公开契约的跨应用写入动作按 V2–V6 的依赖顺序开放。

## 目标

让用户可以通过自然语言或确定性的快捷指令发现和操作 DGOS 中已安装且已授权的应用与系统能力。助手是一个使用公开 DGOS API 的官方应用，不是拥有全局特权的旁路控制器。

## 功能边界

DGOS 是通用应用操作系统。Provider、Skill、MCP、权限、秘密、任务、事件、应用安装和生命周期属于平台能力；无限画布、音乐、天气、二维码、网盘等属于可替换应用。助手通过动作目录连接二者：应用声明可调用动作，平台负责授权和执行，助手负责理解请求、展示计划和反馈结果。

## 来源与追踪

需求：`V1-FR-009`。产品场景见 [V1 PRD](../../../02-产品与版本/当前版本/V1-产品需求.md)；跨功能验收为 `V1-E2E-09`，接口与分支见 [技术设计](02-系统智能助手与动作执行-技术设计.md)。

## V1 范围

包含：

- 默认安装的 `dgos://app/assistant` 官方助手应用和桌面/启动台入口；
- 动作注册与发现：应用声明 `actionId`、输入 schema、所需 capability、风险、副作用、幂等和确认策略；
- 确定性快捷指令：打开/聚焦/关闭应用、打开系统设置或 Provider/Skill/MCP 页面、查询系统/应用/Provider/连接状态、复制可用动作链接；
- 自然语言查询、导航和受控配置：把用户意图解析为已注册动作计划。助手可覆盖大部分 DGOS 系统设置和应用公开配置；低风险读取/导航及可逆设置可按声明直接执行，写入、删除、权限/隐私、秘密/凭据、网络出口、模型调用、有成本或其他外部副作用动作必须显示计划并请求确认；
- 执行状态、取消、失败解释、`requestId`/`taskId`、脱敏审计和结果回链；
- Provider 不可用时快捷指令仍可运行；自然语言理解不可用时显示可执行快捷指令和动作目录。

不包含：V1 项目/画布编辑，节点运行，资产分享/删除，未有公开写契约的跨应用任意写入，组织/团队管理，未注册的任意代码执行，或通过助手读取应用私有数据库、秘密和供应商凭据。应用配置动作只有在应用公开写 API、权限、风险和 E2E 就绪后才可进入 V1 动作目录。

## 需求说明

### 用户故事

作为 DGOS 用户，我希望用一句话或一个快捷指令打开应用、查询状态和进入配置页面；作为应用开发者，我希望按统一规范声明动作，让用户和助手可以安全地发现和调用我的功能。

### 业务规则

1. 每个动作使用全局稳定的 `actionId`；展示名、自然语言别名和翻译文本不能替代稳定身份。
2. 动作必须声明 `inputSchema`、`outputSchema`、所需 capability、风险等级、外部副作用、是否幂等、是否可取消、确认策略和执行器绑定。
3. 助手只能从当前主体可见、已安装、已启用、已授权且健康的动作目录选择动作；不得根据提示词拼接任意 API 路径、应用 ID、工具名或项目路径。
4. 低风险只读、导航和可逆配置动作可按声明自动执行；写入、删除、权限/隐私、外部网络、网络出口、模型调用、秘密使用、付费/配额消耗和不可逆动作至少需要一次明确确认。高影响动作还需显示目标、影响和输入摘要，必要时使用增强确认或拒绝自动执行。
5. 确定性快捷指令不依赖模型；自然语言解析失败、Provider 不可用或意图不明确时不得猜测执行，必须返回澄清或可用动作。
6. 执行前由 Capability Broker 重新检查主体、动作版本、资源范围和当前权限；页面隐藏按钮或此前的 `allow` 不能代替执行时校验。
7. 每个副作用动作使用幂等 `requestId`；长任务升级为 DGOS `taskId`，支持查询、取消和终态确认。
8. 助手只能通过应用公开的动作契约访问应用能力。应用私有状态、API Key、Cookie、完整 System Prompt、供应商 endpoint 和临时下载 URL 不进入助手上下文或日志。
9. 动作注册、授权、确认、执行、取消、失败和结果回链均写入脱敏审计；审计保存动作稳定身份和版本快照。
10. 应用卸载或动作版本失效时，历史指令保留原始引用并显示 `missing`/`disabled`，禁止静默替换为同名动作。

### 前置依赖与执行边界

本功能依赖已安装且健康的官方助手应用、Action Registry、Capability Broker、Permission、公开动作 schema、Task/Run 服务、目标应用公开接口和脱敏审计。调用前必须确认主体 Session 有效、动作版本仍在目录中、目标资源范围明确、所需 capability 已重新判定；高风险或有副作用动作必须先生成计划并完成确认。Provider/模型只服务于自然语言解析，快捷指令不得依赖 Provider；V2-V6 项目、画布、资产和组织动作不是 V1 的前置依赖。字段和响应 schema 以 OpenAPI/动作声明机器契约为权威。

## 动作声明最小结构

```json
{
  "actionId": "com.example.files.file.open",
  "version": "1.0.0",
  "label": { "zh-CN": "打开文件", "en-US": "Open file" },
  "inputSchema": { "type": "object", "properties": { "fileId": { "type": "string" } }, "required": ["fileId"] },
  "requiredCapabilities": ["dgos.file.read"],
  "risk": "read",
  "sideEffects": "none",
  "confirmation": "none",
  "idempotency": "safe",
  "cancellable": false,
  "handler": "dgos.file.open"
}
```

`handler` 只能引用已注册的 DGOS SDK/capability handler。应用不能通过动作声明提升信任级别或访问未声明能力。

## 主流程

```text
快捷指令或自然语言输入
  -> 解析为动作候选
  -> 过滤安装/启用/授权/健康状态
  -> 生成计划与风险摘要
  -> 低风险自动执行或请求确认
  -> Capability Broker 校验
  -> 统一 Executor 执行
  -> 返回结果/任务状态并写入审计
```

## 异常与边界

- 无匹配动作：返回可执行的快捷指令或澄清问题，不创建副作用。
- 动作权限被拒绝：显示所需 capability、拒绝原因和目标应用，不重试绕过。
- 动作版本/应用缺失：显示原始稳定引用和安装入口，不自动替换。
- Provider/模型不可用：快捷指令照常工作；自然语言入口显示不可用原因并允许切换到快捷指令。
- 执行超时或窗口关闭：保留 `taskId`，可从助手历史查询、取消或恢复；前台结果不得伪造为已完成。

## 页面与交互

助手应用提供输入框、快捷指令入口、动作计划/确认区、执行状态、结果摘要和历史记录。风险、目标、将要修改的资源和预计外部调用在确认前可见。历史只保存脱敏摘要和稳定引用，不保存秘密或完整模型上下文。

## 接口契约

助手只使用 DGOS Action Registry、Capability Broker、Action Executor 和 Task API。动作声明至少包含稳定 `actionId`、版本、输入/输出 schema、capability、风险、副作用、幂等、取消和确认策略；快捷指令使用 `actionId + input`，自然语言只产生候选和结构化输入。服务端必须在执行前重新鉴权并返回结构化错误、`requestId` 和必要的 `taskId`。

### 接口清单

| 能力 | 方向 | 业务约束 |
| --- | --- | --- |
| 动作目录 | 读 | 仅返回当前主体可见且健康的动作 |
| 动作计划 | 写/读 | 计划阶段不产生副作用 |
| 动作执行与运行状态 | 写/读 | 执行前重新鉴权，支持查询/取消 |

### OpenAPI operation 映射

| 业务能力 | operationId | 当前状态 |
| --- | --- | --- |
| 列出动作 | `listActions` | V1 OpenAPI 已声明 |
| 生成动作计划 | `planAction` | V1 OpenAPI 已声明 |
| 执行动作 | `executeAction` | V1 OpenAPI 已声明 |
| 查询动作运行 | `getActionRun` | V1 OpenAPI 已声明 |
| 取消动作运行 | `cancelActionRun` | V1 OpenAPI 已声明 |

### 逐操作契约约束

| operationId | 前置条件 | 成功终态 | 关键失败与无副作用 | 幂等 | 并发 | 重试/超时 | 观测/恢复 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `listActions` | 主体 Session 有效，目录服务可用 | 返回主体可见、健康、已授权动作和版本 | 越权动作不返回，不创建计划或执行 | 不适用：只读；替代验证：目录版本快照 | 以 registryVersion 读取 | GET 2 次、2s | requestId、目录审计；刷新目录 |
| `planAction` | actionId/version 存在，输入通过 schema，主体可见 | 返回脱敏计划、风险、目标和确认要求 | 缺失/无权/输入非法不执行、不写业务状态、不调用 handler | `requestId + actionId + inputDigest`；重复返回同一计划 | action version + resource version 条件 | 解析最多 2 次、3s；不重试副作用 | requestId、计划审计；返回澄清/修正输入 |
| `executeAction` | 计划未过期、确认票据有效、权限重新检查通过 | 创建唯一 ActionRun/Task，返回可查询状态 | 拒绝/版本冲突不调用 handler、不写目标配置、不创建成功运行 | `requestId + actionId + inputDigest + confirmationId` 唯一 | resourceVersion 乐观锁；同一 action/resource 运行锁 | 外部动作按声明最多 2 次退避；总预算由 action contract 给出 | requestId/taskId/runId、调用次数、审计；失败补偿/人工处理 |
| `getActionRun` | runId 属于当前主体且存在 | 返回权威运行状态、结果摘要和终态 | 越权不返回输入/结果，不改变运行 | 不适用：只读；替代验证：终态不可倒退 | runVersion 读取 | GET 2 次、2s | taskId/runId、状态指标；继续查询 |
| `cancelActionRun` | runId 属于主体且运行可取消 | 返回 `cancel_requested` 或最终 `cancelled` | 不可取消返回稳定原因，不重复调用 handler、不回滚无关资源 | `requestId + runId`；重复取消返回原结果 | runVersion 条件更新，取消与终态原子竞争 | 取消请求 1 次、5s；超时保留可查询状态 | requestId、取消审计、外部调用次数；人工处理残留 |

### 错误矩阵

| 场景 | error_key/结果 | 处理要求 |
| --- | --- | --- |
| 动作缺失/禁用 | `action_unavailable` | 保留原稳定引用，不静默替换 |
| 权限或确认不足 | `permission_denied` / `confirmation_required` | 不提交副作用 |
| 运行超时/取消 | `timeout` / `cancelled` | 返回 taskId/runId 的最终状态 |

## 数据与事务

动作注册、授权、确认、执行、取消和结果回链分别记录状态事件；副作用动作以 `requestId` 幂等提交，长任务以 `taskId` 查询和取消。助手历史只保存动作版本快照、脱敏输入摘要、结果摘要和审计引用。动作计划在确认前不产生副作用，批量动作要么整体提交，要么保留明确的部分失败结果。

### 涉及数据

动作声明与版本、候选计划、确认票据、执行运行、requestId/taskId、结果摘要和脱敏审计事件。

### 约束与事务

动作计划与执行分离；副作用动作以 requestId 幂等；长任务状态与取消操作按 runId 原子更新；批量动作明确部分失败。

### 字段读写矩阵

| 数据 | 助手应用 | Action Registry/Executor | 审计 |
| --- | --- | --- | --- |
| 动作声明 | 读取 | 注册/校验 | 版本摘要 |
| 计划/确认 | 创建/确认 | 校验票据 | 记录摘要 |
| 运行/结果 | 读取 | 执行/更新 | 脱敏结果 |

### 状态与生命周期

动作声明：`registered`/`disabled`/`missing`；运行：`planned` -> `awaiting_confirmation` -> `queued` -> `running` -> `succeeded`/`failed`/`cancelled`。

### 物理约束与迁移

actionId + version 唯一；requestId 幂等键不可复用到不同输入；历史记录保存版本快照，动作 schema 变更必须可解释。

### 数据所有权

应用拥有动作声明；DGOS Action Registry 拥有目录和运行状态；助手只拥有脱敏历史和用户确认记录。

### 安全与保留

计划、输入和结果摘要按最小权限和脱敏规则保存；秘密、完整 prompt、私有路径和临时 URL 不进入历史或审计；过期运行按保留策略清理。

## 验收标准

#### AC01 快捷指令不依赖 Provider

Given DGOS 已安装应用目录和系统设置应用，Provider 未配置。

When 用户使用快捷指令打开应用或进入设置。

Then 动作被解析、授权并执行，且不要求调用模型。

并且返回 actionId、ActionRun/结果状态或明确的导航响应和审计 requestId；快捷指令失败时不得创建未确认的副作用运行、调用 Provider 或改变目标配置。

#### AC02 动作目录遵循权限和状态

Given 一个动作未安装、未启用、未授权或健康检查失败。

When 助手解析到该动作。

Then 动作被标记为 `missing`、`disabled`、`denied` 或 `unavailable`，不可执行且不被同名动作静默替换。

并且这些状态可在动作目录和审计记录中观察；不得创建计划之外的 ActionRun、调用 handler、写入目标资源或替换原稳定引用。

#### AC03 高风险动作需要确认

Given 一个动作声明了写入、外部网络、秘密使用或模型调用副作用。

When 用户通过自然语言请求该动作。

Then 助手展示目标、输入摘要、风险和所需权限，只有用户确认后才提交执行。

并且未确认时计划状态保持 `awaiting_confirmation`，不调用 handler、不写入目标资源、不创建成功任务；确认后的 ActionRun、requestId 和审计结果可观察。

#### AC04 应用动作可扩展

Given 第三方应用提供合法 manifest 和动作声明。

When 应用安装、启用并获得权限。

Then 动作进入目录，可被助手发现；应用卸载或动作版本失效后历史引用保持可解释的缺失状态。

并且注册/卸载状态、registryVersion 和历史 `missing/disabled` 引用可查询；卸载失败不得删除其他应用数据、替换历史 actionId 或执行残留动作。

#### AC05 长任务可追踪

Given 动作执行超过前台请求生命周期。

When 用户关闭助手窗口或网络短暂断开。

Then DGOS 返回稳定 `taskId`，用户可以查询、取消和读取最终状态，助手不把未确认终态显示为成功。

并且窗口关闭或断线不得重复调用 handler、创建第二个 Task/Run 或修改已确认的目标状态；查询、取消、终态事件和审计均可通过 taskId 观察。

#### AC06 通过公开动作修改设置与应用配置

Given DGOS 系统设置和一个已安装应用公开了带 schema、capability、风险和副作用声明的配置动作。

When 用户要求助手修改一项可逆的低风险偏好，再要求修改一项涉及权限、隐私、秘密、网络出口或不可逆影响的配置。

Then 低风险动作只在公开契约和执行时授权允许的范围内更新目标配置；关键动作先展示目标、影响和输入摘要，只有用户确认并通过重新鉴权后才执行。拒绝、确认过期、版本冲突或能力不匹配时目标配置保持不变，重复 requestId 不重复执行，审计记录结果但不含秘密。

并且 HTTP 响应、目标配置版本、ActionRun 终态和脱敏审计构成可观察事实；任何失败分支不得调用外部服务、扣费、写入秘密或改变原配置。
