# 08 项目资产与生成历史：技术设计

来源：[功能主文档](01-项目资产与生成历史.md)。功能需求、接口、数据和验收口径以主文档及公共契约为准。

本设计登记在 V1 编号体系中，但属于 V4 结构化创作与资产服务；V1 只读取任务产物并在任务工作区预览，不创建项目资产引用或生成历史。

## 单元契约

| 函数 | 前置条件 | 返回 | 副作用 |
| --- | --- | --- | --- |
| `listHistory`（V4） | 用户有项目读取权限 | 分页历史记录 | 读取 DGOS Task/Artifact 索引 |
| `listAssetGrants`（V4） | 用户是资产所有者/管理员或被授予授权查看能力 | 脱敏授权列表 | 只读授权索引，不返回秘密或私有路径 |
| `createAssetRef`（V4） | artifact 可读且项目可写 | 新节点或引用边 | 幂等写入项目文档 |
| `removeAssetView`（V4） | 已计算引用闭包 | hidden/removed 或拒绝原因 | 更新历史视图或请求 DGOS 清理 |
| `evaluateAssetAccess`（V4） | 身份、来源资产和目标项目上下文完整 | `allow/ask/deny`、原因和有效能力 | 只读 DGOS 权限/artifact 状态，不写业务数据 |
| `createAssetGrant`（V4） | 分享者拥有 `share.manage`，目标主体有效 | 授权记录和最终状态 | 幂等创建 `AssetGrant`，写审计摘要 |
| `revokeAssetGrant`（V4） | 分享者拥有授权管理权，授权存在 | 撤销结果和生效时间 | 标记授权 revoked，使后续引用重新解析为不可用 |
| `createCrossProjectReference`（V4） | 来源具备 `reference.create`，目标项目可写，artifact 版本可读 | `AssetRef` 和引用记录 | 不复制媒体；幂等写入目标项目及审计 |
| `importAssetCopy`（V4） | 来源具备 `copy.import`，目标项目可写，预览/复制能力可用 | 新目标资产、导入记录和 provenance | 创建独立目标资产；失败不得写半成品 |

### 授权与状态边界

`evaluateAssetAccess` 是所有分享、引用和复制导入动作的唯一判定入口。它按“身份有效 → 来源资产可见 → 具体能力授权 → 目标项目权限 → artifact 可用”顺序计算，任一 `deny` 都终止操作；`ask` 只能在没有副作用的确认阶段返回。页面隐藏按钮、历史缓存和已存在的本地节点不能绕过该判定。

`AssetGrant.status` 只允许以下状态：

- `active`：授权可用于其声明的能力和有效期。
- `revoked`：所有者或资产管理员主动撤销，新的引用/导入请求立即拒绝。
- `expired`：授权到达 `expiresAt`，不得自动续期。
- `access_revoked`：来源项目、artifact 或 DGOS 权限变化导致授权无法兑现；保留记录用于审计和 UI 解释。

`AssetRef.accessMode` 只能是 `reference` 或 `copy`。`reference` 保存来源资产和固定 artifact 版本，不保存媒体副本；`copy` 只用于导入后目标侧的独立资产，必须有 `AssetImportRecord` 和 provenance。引用可用性至少包括 `available`、`access_revoked`、`unavailable` 和 `removed`。

### 数据边界

```text
AssetGrant {
  id, assetId, sourceProjectId, granteeType, granteeId,
  capabilities[], status, expiresAt?, createdBy, createdAt,
  revokedBy?, revokedAt?, reason?
}

AssetRef {
  id, artifactId, sourceProjectId?, sourceAssetId?, artifactVersion?,
  grantId?, accessMode, availability, createdBy, createdAt
}

AssetImportRecord {
  id, requestId, sourceAssetId, sourceProjectId, sourceArtifactVersion,
  targetProjectId, targetAssetId, importedBy, mode: "copy",
  provenance, status, createdAt, completedAt?, errorCode?
}
```

上述字段是 DGOS 业务边界，不是底层数据库 schema。项目文档只持久化 `AssetRef` 的稳定引用和布局信息；秘密、完整媒体内容、私有路径和临时下载地址必须留在 DGOS Secret/Artifact 能力域。

## 伪代码

```text
createAssetRef(projectId, artifactId, requestId):
  REQUIRE ownsProject(projectId)
  // B08-01
  artifact = dgos.artifact.read(artifactId)
  IF artifact.unavailable:
    RETURN Err("artifact_unavailable")
  // B08-02
  IF project.hasRequest(requestId):
    RETURN project.requestResult(requestId)
  // B08-03
  node = project.addNode({ kind: "asset-ref", artifactId, sourceTaskId: artifact.taskId })
  project.write(node, requestId)
  RETURN Ok(node)

removeAssetView(projectId, artifactId):
  refs = project.findRefs(artifactId)
  // B08-04
  IF refs.count > 0:
    RETURN Ok({ state: "hidden", reason: "still_referenced" })
  // B08-05
  history.hide(artifactId)
  RETURN Ok({ state: "removed" })

evaluateAssetAccess(actor, sourceAsset, targetProject, capability):
  REQUIRE actor.identityValid
  IF NOT sourceAsset.visibleTo(actor):
    RETURN Deny("source_asset_forbidden")
  owner = sourceAsset.ownerIs(actor)
  grant = owner ? null : sourceAsset.grantFor(actor, capability)
  IF NOT owner AND NOT grant:
    RETURN Deny("capability_missing")
  IF NOT owner AND grant.expiresAt AND now >= grant.expiresAt:
    grants.transition(grant.id, "expired")
    RETURN Deny("grant_expired", { grantId: grant.id })
  IF NOT owner AND grant.status in ["revoked", "expired", "access_revoked"]:
    RETURN Deny("grant_unavailable", { grantId: grant.id })
  IF NOT owner AND capability not in grant.capabilities:
    RETURN Deny("capability_missing")
  IF targetProject AND NOT targetProject.writableBy(actor):
    RETURN Deny("target_project_forbidden")
  IF NOT dgos.artifact.versionReadable(sourceAsset.artifactId, sourceAsset.artifactVersion):
    RETURN Deny("artifact_unavailable")
  RETURN Allow({ grantId: grant?.id, artifactVersion: sourceAsset.artifactVersion })

createAssetGrant(actor, sourceAsset, grantee, capabilities, expiresAt?, requestId):
  REQUIRE evaluateAssetAccess(actor, sourceAsset, null, "share.manage") == allow
  REQUIRE capabilities is non-empty and capabilities subset of knownCapabilities
  REQUIRE "reshare" is absent unless actor is sourceAsset.ownerOrAssetAdmin
  IF idempotency.exists(requestId): RETURN idempotency.result(requestId)
  grant = grants.upsert({ sourceAsset, grantee, capabilities, expiresAt }, requestId)
  audit.append("asset.share.created", grant.summary)
  RETURN Ok(grant)

revokeAssetGrant(actor, grantId, requestId):
  REQUIRE actorCanManageGrant(actor, grantId)
  IF idempotency.exists(requestId): RETURN idempotency.result(requestId)
  grant = grants.transition(grantId, "revoked")
  audit.append("asset.share.revoked", grant.summary)
  RETURN Ok(grant)

createCrossProjectReference(actor, sourceAsset, targetProjectId, requestId):
  decision = evaluateAssetAccess(actor, sourceAsset, project(targetProjectId), "reference.create")
  IF decision is deny: audit.append("asset.reference.denied", decision.summary); RETURN decision
  IF idempotency.exists(requestId): RETURN idempotency.result(requestId)
  ref = project(targetProjectId).addAssetRef({
    sourceProjectId: sourceAsset.projectId,
    sourceAssetId: sourceAsset.id,
    artifactId: sourceAsset.artifactId,
    artifactVersion: decision.artifactVersion,
    grantId: decision.grantId,
    accessMode: "reference",
    availability: "available"
  }, requestId)
  audit.append("asset.reference.created", ref.summary)
  RETURN Ok(ref)

importAssetCopy(actor, sourceAsset, targetProjectId, requestId):
  decision = evaluateAssetAccess(actor, sourceAsset, project(targetProjectId), "copy.import")
  IF decision is deny: audit.append("asset.import.denied", decision.summary); RETURN decision
  IF idempotency.exists(requestId): RETURN idempotency.result(requestId)
  source = dgos.artifact.copy(sourceAsset.artifactId, decision.artifactVersion)
  target = project(targetProjectId).createAssetFrom(source, { pending: true })
  record = imports.commit({ sourceAsset, target, requestId, provenance: actor.summary })
  audit.append("asset.import.completed", record.summary)
  RETURN Ok({ target, record })
```

复制导入的实际步骤必须使用可回滚或暂存状态：复制、目标资产登记和 `AssetImportRecord` 提交任一步失败，都要删除未提交的临时目标或标记为不可见，不得留下可被搜索到的半成品。引用和授权写入必须支持并发重复请求；同一 `requestId` 返回原结果，不能创建第二条引用、授权或导入记录。

### 撤销、删除与审计

- 撤销授权不会删除已完成的复制副本；它只使后续请求拒绝，并使引用在下一次解析时转为 `access_revoked`。
- 来源项目删除、artifact 版本过期或 DGOS 权限收紧时，引用保留来源摘要并转为 `unavailable`；用户可以移除本地引用，但不能借此恢复源媒体。
- 删除来源资产前先计算引用闭包。仍有引用时使用 `hidden/removed` 或返回依赖冲突，物理清理由 DGOS 保留策略决定。
- 分享创建、撤销、引用创建、导入完成、拒绝和删除保护都写入审计摘要；审计内容只含稳定 ID、能力、状态、时间和主体摘要，不含秘密、私有路径或完整媒体。
- 默认不授予 `reshare`。即使主体拥有 `reference.create` 或 `copy.import`，也不能把来源资产再次分享给第三方。
