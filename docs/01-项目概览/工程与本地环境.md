## 4. 本地执行入口与证据边界

使用package.json登记命令：`pnpm install --frozen-lockfile`、`pnpm run check`、`pnpm -r build`、`pnpm test`、`pnpm run test:integration`、`pnpm run test:web:e2e`。PG/Redis测试缺环境可能skip，需核对实际统计；并行工作包使用独立数据库/端口，不对原业务库清空或回滚。专用Compose拓扑和历史真实命令见[F报告](../05-测试与发布/端到端验收/报告/V1-F-整合联调报告.md)，不能直接将其清理命令用于用户原环境。

真实Provider、macOS GUI/签名、生产Secret、灾备与发布验证分别留证；构建成功不等于GUI通过，Redis开发Secret不等于生产backend。真实密钥不写仓库。已存在源码与历史本地报告，但不代表完整V1或发布通过。
