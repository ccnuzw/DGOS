# 全版本产品与交互约束

| 编号 | 约束 | 适用范围 | 例外与决策 |
| --- | --- | --- | --- |
| GC-01 | APP 只能通过 DGOS 版本化 API/SDK 访问系统服务；不得依赖 DX OS 私有 Bridge | 全版本 | D013 |
| GC-02 | V2+ 项目主数据使用 DGOS Project API；大型媒体只保存稳定引用，不把 Base64 写入项目文档 | V2+ | D013、D008、D012 |
| GC-03 | AI 图片/视频/音频/转录使用 DGOS AI Task API，不得自拼供应商 endpoint 或 API Key | 全版本 | D004、D013 |
| GC-04 | Skill 和 MCP 在 V1 必须声明依赖、权限、风险和副作用；动态 Canvas 插件在 V5 适用同一约束 | V1/V5 | V1-FR-003、V1-FR-006（V5） |
| GC-05 | 异步操作必须显示 loading、终态、错误和可追踪 id；不得静默重复副作用 | 全版本 | V1-FR-005 |
| GC-06 | 所有第一方和第三方 APP 必须使用 DGOS Design Tokens 与公开 UI Kit；应用可以扩展领域 token，但不得覆盖系统主题、字体、窗口、权限或状态语义 | 全版本 | D028、ADR-0004 |
| GC-07 | 窗口、页签、主题、语言地区、权限提示、任务中心、通知、错误边界和系统上下文由 DGOS Shell/平台服务统一提供，应用不得自建平行实现 | 全版本 | D025、D028、ADR-0004 |
| GC-08 | 桌面与 Web 共用路由、组件语义、快捷命令、任务状态和 API 事件；文件、窗口、钥匙串、通知等宿主差异必须隔离在 Host Adapter | 全版本 | D019、D027、D028、ADR-0004 |
| GC-09 | 每个异步操作和副作用必须显示发起、进行中、成功、失败、取消或无权限状态，并提供查询、重试、取消、恢复或明确终止路径 | 全版本 | D028、ADR-0004 |
| GC-10 | 所有版本必须支持国际化、键盘和辅助技术、可见焦点、动态字号、减少动态效果、秘密脱敏与安全日志；关键语义不能只依赖颜色、hover 或拖放 | 全版本 | D025、D028、ADR-0004 |

## 使用规则

违反约束时先登记冻结决策，再修改功能文档和实现；视频或旧项目画面不能直接成为例外依据。
