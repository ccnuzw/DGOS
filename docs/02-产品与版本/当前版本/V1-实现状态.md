更新时间：2026-10-01。状态依据当前仓库代码、页面和已记录验证，不把“存在代码”直接等同于“已验收”。当前仓库无 DGOS 产品源码，因此 V1 处于规格收敛与门禁评审中，不能据此批量进入生产实现。详细任务与证据见各功能主文档的“实现与验证”章节。V1 由平台控制面、系统服务和唯一业务示范 APP DGOS AI 工作台组成；基础闭环为 FR-001/005/007，平台最小支撑为 FR-002/003/009/010/011/012/013/014/015；FR-004/006/008 及 FR-005/007 高级子集按 V2–V5 分阶段交付，不计入 V1 首发门禁。FR-002 包括最小审核准入、受信目录和普通用户应用生命周期；V1 不含评分、收费和规模化市场运营。系统助手（FR-009）目标覆盖大部分公开系统设置与应用配置动作，具体仅限有公开契约、权限策略和验收的动作；高风险动作须确认。

## 状态使用规则

- **规划中**：已确定范围，尚未进入开发。
- **开发中**：已开始实现，未满足全部功能验收。
- **部分实现**：只覆盖部分接口、部分 UI 或缺少冻结决策要求。
- **基础实现**：主链路已有代码，但未满足全部功能验收。
- **本地验证**：不能作为真实外部依赖或发布门禁的最终证据。
- **待验收 / 已完成**：功能升为“待验收”前，必须在对应功能主文档的“实现与验证”章节填写日期、环境、构建标识、命令/用例和结果。
- 本表是实现状态的唯一维护位置；功能主文档与索引不复制状态值。
