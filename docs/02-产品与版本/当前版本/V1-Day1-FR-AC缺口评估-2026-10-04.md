## 逐 FR AC 判定

### FR-001 桌面与应用工作区（P0）

规格要求 AC01–AC08：启动窗口、校验失败无副作用、系统/应用状态、主题倍率上下文、语言地区分离、代理重启、系统拒绝优先、启动权限与能力权限分离。

- **部分满足**：AC01、AC03、AC04、AC07、AC08。已有 macOS/debug、API、签名包 fixture、权限子集；Native loopback 证据已覆盖 frame/handshake/Task/Artifact/reload，但不是正式签名候选。
- **未满足**：AC02 真实包校验失败保留旧版本；AC05 地区格式与助手语言在双宿主；AC06 GUI 代理录入/重启后真实路由。
- **主要缺口**：正式 dist 同源重建、签名/公证决策、人工可见 UI、负向无副作用、Web/Native 一致性。

### FR-002 开发者中心与 APP 生命周期（P0）

AC01 manifest/资源校验，AC02 版本发布/健康失败回滚，AC03 审核目录和普通用户安装更新卸载。

- **部分满足**：AC01–AC03。W4 FR002 26 tests PASS，历史 G r11 公开链通过。
- **未满足**：当前冻结候选上的完整浏览器/Native入口、正式信任根、跨进程锁压力、中断恢复、目标发布渠道。

### FR-003 Skill/MCP/Agent 接入（P0）

AC01 未授权拒绝；AC02 超时追踪；AC03 MCP 配置脱敏；AC04 Skill 导入/启用/移除保护；AC05 快速配置凭据；AC06 MCP 生命周期；AC07 Skill 预览；AC08 bundled MCP 与持久 Run。

- **部分满足**：AC01–AC06。E r6 33/33、旧 Run 链 12/12 和 PG/daemon 子集存在。
- **未满足**：AC07 当前真实 Web 导入预览/确认；AC08 页面关闭/reload 后持久 Run 的当前候选闭环。
- **额外阻塞**：W4 FR003 整组 BLOCKED，故不能用旧局部批次关闭门禁。

### FR-004 无限画布与项目（P2）

无 V1 AC 执行范围。V2–V5 规划，延后，不创建 V1 缺口包。

### FR-005 多模态 AI 任务工作流（P0，V1 文本子集）

V1 AC01 文本任务闭环、AC02 失败/重复提交、AC08 流式/断线恢复。

- **部分满足**：AC01、AC02。Provider worker、Task、Artifact、取消和局部幂等有本地/Native debug证据。
- **未满足**：AC08 在统一 Web + Native 冻结候选上的 SSE cursor、刷新恢复和真实 Provider 证据；W4 Web 组 BLOCKED。

### FR-006 Canvas 插件与模板扩展（P2）

V5 规划，不属于 V1，延后。

### FR-007 模型平台与工作流配置（P0）

AC01 Provider 验证；AC02 失败保护；AC04 openai-compatible descriptor；AC05 分类/启用/文本筛选；AC06 不提供导出；AC07 显式刷新；AC08 Model Profile；AC09 声明式 text.chat 执行。

- **部分满足**：AC01、AC04、AC05、AC06、AC07、AC09。配置 API、模型目录、脱敏、文本任务和 no-export 局部通过。
- **未满足**：AC02 当前候选失败停用/既有任务收敛的完整 UI/E2E；AC08 全模型 Profile/未映射拒绝和真实外部 Provider。
- **门禁缺口**：验证与刷新两步、失败不清空历史、并发刷新、选择器同步必须在当前候选复验。

### FR-008 项目资产与生成历史（P2）

V4 规划，不属于 V1，延后。

### FR-009 系统智能助手与快捷指令（P0）

AC01 无 Provider 快捷指令；AC02 动作状态；AC03 高风险确认；AC04 应用动作注册；AC05 长任务追踪；AC06 公开动作写设置/应用配置。

- **部分满足**：AC01、AC02、AC03、AC06。Action resolver、权限、确认、设置原子写入和审计有局部证据。
- **未满足**：AC04 安装/卸载后的动作 registry/history 完整生命周期；AC05 独立进程/窗口关闭/断线恢复的当前候选证据。
- **W4 状态**：FR009 BLOCKED，不能将内存/API 测试当作完整助手 E2E。

### FR-010 管理员登录与会话（P0）

AC01 首次引导、AC02 登录失败保护、AC03 会话撤销、AC04 高风险再认证。

- **部分满足**：AC01–AC03。Identity r12 20/20 覆盖双 API/PG/Redis 局部。
- **未满足**：AC04 在全部高风险入口和最终双宿主候选上的 step-up/session-expired 证明；生产 Secret/TLS/目标部署也未验。

### FR-011 API Key 生命周期（P0）

AC01 一次性创建、AC02 scope、AC03 轮换、AC04 撤销/过期。

- **部分满足**：AC01、AC02、AC04，已有一次性明文、digest、scope、撤销/过期局部证据。
- **未满足**：AC03 当前候选轮换窗口、失败原子性、双有效状态审计及全入口 UI/生产 Secret。

### FR-012 Provider 账号与连接（P0）

AC01 账号凭据、AC02 明确绑定、AC03 禁用传播、AC04 引用保护。

- **部分满足**：AC01、AC02，公开账号/SecretRef/绑定和权限基础存在。
- **未满足**：AC03 停用传播到新任务但保留旧任务；AC04 account_in_use、SecretRef/历史保护。

### FR-013 上游账号连接测试（P0）

AC01 成功诊断、AC02 失败分类、AC03 SSRF/权限边界、AC04 超时取消。

- **部分满足**：AC01、AC02、AC04，worker lease、分类、取消和唯一终态有本地证据。
- **未满足**：AC03 在目标候选/真实网络环境的 SSRF、DNS rebinding、跳转和越权拒绝完整证据；UI 诊断也未闭合。

### FR-014 审计与管理员治理（P0）

AC01 高风险审计、AC02 脱敏查询、AC03 审计不可用 fail-closed、AC04 保留清理、AC05 策略 CAS 冲突。

- **部分满足**：AC01–AC04，outbox、脱敏、retention、引用保护子集存在。
- **未满足**：AC05 全部治理策略路由的并发新鲜认证、conflict、审计保留和当前候选 UI；目标恢复/RPO/RTO 也缺失。

### FR-015 用量与额度管理（P0）

AC01 硬额度预检、AC02 并发预留、AC03 唯一结算、AC04 unavailable/estimated、AC05 权限隔离。

- **部分满足**：AC01–AC04，quota reservation、settlement、重复事件保护和 unavailable 状态有本地证据。
- **未满足**：AC05 全部管理 UI/资源级边界与当前候选；跨 Provider/真实 usage、性能和发布环境仍未证。
