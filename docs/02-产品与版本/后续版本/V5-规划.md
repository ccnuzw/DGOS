# V5 3D 与扩展生态规划

## 定位与边界

V5 依赖 V2 项目、V3 运行与 V4 资产边界，交付独立 3D 导演台场景/相机/时间线、截图或视频 artifact 回写，以及 Canvas 插件和模板的隔离安装、升级、卸载和失败回滚。历史 `V1-FR-006` 见[规划登记稿](../../03-功能规格/V5/06-插件扩展/01-Canvas插件与模板扩展.md)，导演台专项设计仍为 Draft；多人协作和市场规模化分发归 V6。

## 用户路径与验收方向

创作者从画布打开导演台，编辑场景并保存重开；导出固定机位/时间线快照，完成后生成稳定 artifact 与新画布节点。取消或渲染失败不得出现半成品，删除导演台不删除已回写产物。开发者安装插件，升级包无效时旧版本与隔离数据保留。原 `V1-E2E-04D/06` 拟迁移为 `V5-E2E-01/02`，正式编号待 V5 门禁冻结。

| 历史引用 | V5 归属行为 | 新编号状态 |
| --- | --- | --- |
| `V1-FR-004/AC13` | 导演台场景、时间线、截图/视频回写 | V5 AC 待门禁分配 |
| `V1-FR-006/AC01–AC04` | 插件/模板安装、运行、隔离、回滚 | V5 AC 待门禁分配 |
| `V1-E2E-04D/06` | 导演台与插件闭环 | 拟定 `V5-E2E-01/02`，待门禁冻结 |

Given 画布中有可读场景资源和已校验插件包。When 用户导出固定快照并回写，或升级插件时注入无效包。Then 只在成功后生成稳定 artifact/节点；取消和失败不留半成品，旧插件版本与隔离数据保留。此处仅为规划验收方向，正式 AC/E2E 待 V5 门禁冻结。

## 契约与数据方向

Director 服务拥有场景和时间线，Project 只持有节点引用，Artifact 持有导出产物，Extension Runtime 持有插件隔离状态。渲染能力、包签名、节点注册、数据迁移和物理表目前未冻结；需独立 schema、OpenAPI/SDK 契约及 migration 验证。
