# V4 结构化创作与资产服务规划

## 定位与边界

V4 依赖 V3 可追踪的画布运行和稳定 artifact，增加多维表格、资产库与生成历史、显式分享/撤销、跨项目引用或复制导入、画布 Agent、供应商节点以及高级工作流配置。历史 `V1-FR-008` 的资产设计见[规划登记稿](../../03-功能规格/V4/08-资产与历史/01-项目资产与生成历史.md)；`V1-FR-005/007` 的 V4 方向不属于 V1 AC。3D、Canvas 插件及组织协作仍排除。

## 用户路径与验收方向

创作者从 V3 运行结果进入资产库，筛选并授权另一主体；目标项目选择引用或复制导入。撤销后引用显示不可用，已完成副本保留独立所有权；失败导入不生成目标资产。供应商能力缺失、Agent 未授权或表格冲突均须拒绝且无外部副作用。原 `V1-E2E-04C/08` 拟迁移为 `V4-E2E-01/02`，正式编号待 V4 门禁冻结。

| 历史引用 | V4 归属行为 | 新编号状态 |
| --- | --- | --- |
| `V1-FR-004/AC07/AC08` | 表格隔离、历史/资产回用、Agent 权限 | V4 AC 待门禁分配 |
| `V1-FR-005/AC03/AC04/AC06/AC07` | 多媒体输入、ComfyUI、供应商节点、Agent 任务关联 | V4 AC 待门禁分配 |
| `V1-FR-007/AC03` | ComfyUI/供应商运行配置 | V4 AC 待门禁分配 |
| `V1-E2E-04C/08` | 结构化创作、资产授权与跨项目复用 | 拟定 `V4-E2E-01/02`，待门禁冻结 |

Given V3 运行结果和明确的资产授权、已注册的供应商能力。When 用户筛选资产、撤销授权、选择引用或复制导入，或在表格/供应商节点发起任务。Then 来源引用状态与复制副本所有权分离，Agent/供应商任务分别追踪；权限、输入或配置失败不生成目标资产、任务或外部请求。此处仅为规划验收方向，正式字段与 AC 由 V4 门禁冻结。

## 契约与数据方向

Project 持有表格与项目引用，Artifact 持有原件，Permission 持有授权，导入服务持有复制事务。`dgos.asset.*` 及供应商节点目前是 Draft 逻辑方向，字段、错误、幂等和 DDL 未冻结；须补 V4 OpenAPI、授权/撤销事务、删除引用闭包和 migration 验证。
