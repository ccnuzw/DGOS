# V3 画布工作流规划

## 文档定位与状态

本文是 V3 的独立版本规划文件，维护范围、依赖和进入开发门禁前的方向。V3 尚未通过[版本进入开发门禁](../版本进入开发门禁.md)，因此本文不是直接编码输入，不分配 `V3-FR`、`V3-NFR` 或 `V3-RG` 编号，也不代表任何能力已经实现。

正式开发前，需保留跨版本延续的 `V1-FR-004/005/007` 稳定 ID，仅为新增的独立验收目标分配 V3 正式编号；随后拆成功能主文档、技术设计、接口、数据、测试和证据空间，并与当前实现状态分离维护。

## 版本目标

在 V2 已稳定的项目、画布、端口和保存恢复能力上，引入可追踪的画布工作流执行。创作者可以把节点图转换为受控任务运行，看到状态、进度和结果，并在失败、取消、重试或重新打开后继续追踪同一运行。

## 做什么

- 生成卡片、LLM 和结果节点的执行配置与动态参数界面。
- 根据已启用模型的能力描述生成节点字段、端口和校验提示。
- 将节点运行统一提交到 DGOS AI Task，不在节点内部创建第二套执行器。
- 建立 `runId`、`requestId`、节点运行记录和结果批次之间的可追踪关系。
- 支持运行状态、进度、取消、停止、受控重试、错误映射和结果回写。
- 保存运行快照，允许在页面刷新、断线或重新打开项目后恢复观察。
- 为循环和级联提供受控的图校验、深度/数量限制和失败边界。
- 提供基础运行历史，能从节点回到任务、artifact 和错误详情。

## 明确不做

- 跨项目资产分享、授权、复制导入和组织级资源策略。
- 多维表格、并发编辑和表格公式运行时。
- ComfyUI、Midjourney 等供应商专用节点或 GPU 工作流运行时。
- 3D 导演台、时间线、全景和媒体导出。
- Canvas 插件市场、第三方扩展运行时和模板生态运营。
- 多人实时协作、冲突合并、组织/团队和移动端体验。

## 上游依赖

| 依赖 | 要求 |
| --- | --- |
| V2 Project API | 项目读写、版本校验、画布文档 schema、端口/连线规则和保存恢复已冻结。 |
| V1 AI Task API | Provider/Model Catalog、能力 descriptor、任务状态、SSE/轮询、取消和错误映射可被画布消费。 |
| Artifact 服务 | 结果 artifact 有稳定引用、版本和读取权限，不把大型媒体写入项目 JSON。 |
| Permission/Secret/Action | 节点执行沿用统一权限、秘密隔离和审计边界。 |

## 架构影响

- Canvas Executor 作为 DGOS 画布域的编排层，调用统一 AI Task API；Provider、模型适配和秘密处理仍归平台能力平面。
- 节点状态与 AI Task 状态分离保存，通过 `runId`、`requestId`、`taskId` 和结果批次建立关联。
- 每次运行生成不可变运行快照，记录节点配置摘要、输入引用、能力和模型版本；不保存 API Key 或完整秘密。
- 取消、恢复、幂等和失败补偿必须跨页面生命周期成立，不能依赖某个窗口常驻内存。
- 循环和级联在提交前做静态图校验，在运行时执行深度、节点数、并发和超时限制。

## 数据影响

仅定义方向性实体，待门禁后冻结字段和迁移：

- `CanvasRun`：项目、画布、发起主体、运行状态、时间和取消信息。
- `NodeRun`：节点快照、输入摘要、任务引用、状态、错误和重试次数。
- `RunSnapshot`：可恢复的图版本、执行计划和依赖版本。
- `ResultBatch`：结果顺序、artifact 引用、来源 task 和回写状态。
- `RunEvent`：状态变化、进度、取消、恢复和审计事件。

节点配置只保存稳定引用和可审计参数摘要；artifact 原件归 Artifact 服务，秘密归 Secret 服务。

## 接口方向

以下仅表示领域方向，不冻结 schema 或 operationId：

- `dgos.project.*`：读取项目/画布版本与提交运行前的结构校验。
- `dgos.aiTask.*`：提交、流式事件、查询、取消、重试和结果读取。
- `dgos.artifact.*`：结果引用、版本和权限校验。
- `dgos.canvasRun.*`：运行创建、快照、恢复、节点状态和基础历史。

统一错误语义、幂等键、事件顺序和断线恢复协议必须在技术设计和 ADR 中冻结后才能实现。

## 验收方向

### 历史 AC 与 E2E 迁移

| 历史引用 | V3 归属行为 | 新编号状态 |
| --- | --- | --- |
| `V1-FR-004/AC05/AC11` | 生成卡片/LLM 执行、节点状态、循环/级联与结果批次 | V3 功能拆分及 AC 待门禁分配 |
| `V1-FR-005/AC05` | 动态 schema 约束的画布节点任务与 artifact 回写 | V3 AC 待门禁分配 |
| `V1-FR-007/AC03` | AI 应用/画布工作流启停和配置 | V3/V4 切片与 AC 待门禁分配 |
| `V1-E2E-04B` | 画布工作流闭环 | 拟定 `V3-E2E-01`，待门禁冻结 |

Given V2 项目可读写、V1 Task/Artifact 可用且用户有执行权限。When 用户在生成卡片或 LLM 节点配置动态参数并运行、停止或重试。Then 运行快照固定输入/能力版本，任务状态和结果按批次回写；非法参数/无权/失败不产生半成品节点或重复任务。工作流配置停用后不接受新运行，不改写已有项目和任务。此处仅为规划验收方向，不是正式 AC 或已执行用例。

- 正常输入能从画布运行到成功终态，结果以稳定 artifact 引用回写到结果节点。
- Provider、模型能力、参数或端口不满足条件时，提交前给出可解释拒绝，不创建半成品运行。
- 任务失败、超时、取消和受控重试均保留原始错误、运行关联和最终状态。
- 页面刷新、断线和重新打开项目后，能依据快照和 taskId 恢复运行观察。
- 结果回写具备幂等性，重复事件不会产生重复节点、artifact 或边。
- 非法循环、超过限制的级联、重复运行和权限不足都被稳定拒绝并审计。

## 主要风险

| 风险 | 影响 | 门禁前处理方向 |
| --- | --- | --- |
| 循环或级联缺少上限 | 无界任务、费用和资源消耗 | 冻结图校验、运行配额、停止条件和拒绝语义。 |
| 节点状态与 Task 状态分叉 | 页面显示成功但结果缺失，或重复回写 | 冻结事件顺序、幂等键、终态判定和恢复流程。 |
| 输入 artifact 权限或版本变化 | 运行结果不可复现、越权读取 | 固定输入版本，执行前重新鉴权并记录来源。 |
| Provider 能力动态变化 | 节点配置失效或静默降级 | 保存能力快照，提交前校验并明确失败。 |

## 进入开发门禁前未决项

1. 是否允许有向环；若允许，最大深度、节点数和停止条件是什么。
2. 节点并发、全图队列和单 Provider 限流采用什么口径。
3. 节点失败后支持局部重试、从失败点继续还是整图重跑。
4. artifact 版本固定、结果替换和重新运行之间的语义。
5. 运行快照的保留期限、体积上限和跨设备恢复范围。

## 门禁状态

`规划骨架`。V3 尚无正式功能编号、可编码接口契约、数据迁移、测试资产或实现证据；不计入 V1 实现状态和当前交付统计。
