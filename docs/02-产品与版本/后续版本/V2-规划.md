# V2 项目与画布基础规划

## 定位与边界

V2 以 V1 平台、主体和权限为前提，交付正式个人登录/会话、DGOS Project 持久化、项目列表、画布导航、内容节点、视口、基础端口/连线/分组、保存恢复与结构导入导出。历史编号 `V1-FR-004` 的 V2 切片见[规划登记稿](../../03-功能规格/V2/04-无限画布/01-无限画布与项目.md)，该编号不代表 V1 已交付。节点执行、生成卡片/LLM 运行、资产库、表格、Agent、3D 和插件不属于 V2。

## 用户路径与验收方向

用户登录后创建项目，从项目列表打开空白画布，添加内容节点并建立合法连接，保存、关闭、重新打开后节点/边/视口一致。非法连接、冲突版本或不兼容导入须在提交前拒绝，原项目不变；退出会话不得删除项目。原 `V1-E2E-04A` 迁移为拟定 `V2-E2E-01`，正式 ID 在 V2 门禁冻结。

## 契约与数据方向

Project 服务拥有项目文档和版本，Identity 拥有正式会话，Permission 在读写时重新校验主体；Artifact 只持有被引用产物。`dgos.project.*` 目前只有逻辑方向，V1 OpenAPI 没有该操作；请求/响应、并发版本、导入 schema、事务及迁移需在 V2 OpenAPI 与 migration 冻结后才能编码。
