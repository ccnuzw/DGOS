# DGOS 功能演进矩阵

## 1. 文档职责

跨版本能力演进的聚合视图；只做索引，不复制各版本文档的规则。版本边界仍以[版本路线图](版本路线图.md)为准。

## 2. 状态口径

| 状态 | 含义 |
| --- | --- |
| 已发布 | 在当前生产版本可用 |
| 活跃开发 | 当前版本范围内，按功能状态推进 |
| 规划中 | 已确定归属版本，尚未进入开发 |
| 候选 | 有方向但未冻结归属 |

## 3. 跨版本总览

### 3.1 版本主链路

```text
V1 DGOS 平台与线性任务
  -> V2 项目与画布基础
  -> V3 画布工作流
  -> V4 结构化创作与资产服务
  -> V5 3D 与扩展生态
  -> V6 协作与生态规模化
```

## 4. 分域演进

以下分域表只列本域能力的版本变化摘要，并链接到权威文档。

### 4.1 项目与画布

| 能力 | 变化 | 版本 | 权威文档 |
| --- | --- | --- | --- |
| 项目读写、画布导航、内容节点 | 建立可保存恢复的项目与基础图编辑 | V2 | [无限画布与项目](../03-功能规格/V2/04-无限画布/01-无限画布与项目.md) |
| 执行节点、循环、结果回写 | 在稳定图编辑上接入可追踪任务 | V3 | [V3 画布工作流规划](后续版本/V3-规划.md) |
| 表格、资产、Agent、供应商节点 | 增加结构化数据、权限和外部能力 | V4 | [版本路线图](版本路线图.md) |
| 导演台、插件、模板 | 引入高依赖渲染和扩展隔离 | V5 | [3D 导演台专项](../03-功能规格/V5/04-无限画布/03-3D导演台专项-技术设计.md) |

## 6. 维护规则

1. 本矩阵只聚合，不新增规则；某项能力变化必须能指向功能主文档或版本规划。
2. 能力增强导致接口/数据破坏性变化时，登记到冻结决策与文档变更记录。
3. 需要按单个功能查看跨版本时间线时，可另建“具体功能演进索引”，但不得与功能文档并列为第二事实源。
