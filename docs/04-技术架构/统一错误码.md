# DGOS 统一错误码

V1 当前冻结业务级错误语义，传输方式可以是 IPC 或 HTTP；数值码待 DGOS API schema 冻结后登记，不在 V1 虚构传输层错误。

## 必须保留的业务错误语义

| error_key | 触发条件 | 负责功能 |
| --- | --- | --- |
| `permission.denied` | 清单未声明或用户未授权 | V1-FR-002/003；V1-FR-006（V5） |
| `input.invalid` | schema/协议输入不合法 | V1-FR-003/005；V1-FR-006（V5） |
| `model.unavailable` | handshake 返回 unavailable/legacy | V1-FR-005 |
| `task.failed` | AI/Agent 任务进入失败终态 | V1-FR-003/005 |
| `project.version_conflict` | 项目 baseVersion 过期 | V1-FR-004（V2） |
| `plugin.rollback` | 插件升级健康检查失败 | V1-FR-006（V5） |

## 原则

- 错误必须包含可追踪的 request_id 或 taskId，不能暴露 token、堆栈或供应商密钥。
- 同一失败原因只保留一个稳定语义；传输层映射由 DGOS API 适配层维护。
