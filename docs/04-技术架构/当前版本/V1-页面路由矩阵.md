## 后续路由预留

以下路由不属于 V1 首发入口，仅记录未来应用化承载方向；进入对应版本门禁后才转入当前路由矩阵并补齐功能规格和 E2E：

| 路由 | 页面 | 目标版本 | 关联功能 |
| --- | --- | --- | --- |
| `dgos://app/files` | 文件应用 | V2–V6 | 后续第一方应用 |
| `dgos://app/dgos/assets` | 项目资产与生成历史 | V4 | V1-FR-008 |

系统设置页固定包含以下分组：

| 分组 | 主要设置 | 运行时影响 |
| --- | --- | --- |
| 外观 | 浅色/深色/跟随系统、窗口材质、界面模式、75–175% 缩放、明暗壁纸 | 注入 `SystemContextSnapshot.appearance`，应用不能自行覆盖 DGOS 窗口和倍率 |
| 语言与地区 | 界面语言、生效语言、地区格式、助手回复语言、项目内容语言 | 分别影响系统文案、格式化、助手输出和项目默认语义；不自动翻译已有内容 |
| 网络 | 系统/手动/关闭代理、有效路由、重启状态 | Provider、模型拉取、Skill/MCP 在线导入使用统一出口 |
| 网格 | 点/线、间距、主网格频率、坐标轴、吸附、透明度 | 作为 DGOS 系统层网格 token 提供给支持网格的 APP；V2 画布再保存项目级可见性 |
| 隐私与安全 | 文件、MCP、Skill 等 capability 的 `allow / ask / deny` | broker 在副作用前重新计算，`deny` 优先 |
| APP 权限 | 打开 APP 与 Agent 能力分开授权 | APP 已启动不代表能写文件、调用 MCP、运行 Skill 或打开外部页面 |

## 公共页面状态

| 状态 | 行为 |
| --- | --- |
| 未登录 | V1 使用受控本地/适配器会话；V2 正式登录后跳转身份入口并安全回跳原路由 |
| 无权限 | 显示稳定错误键、所需 capability 和 requestId；不通过前端隐藏按钮代替鉴权 |
| 数据不存在 | 返回稳定 404 错误键；不以空对象伪装资源存在 |

## 路由变更规则

1. 新增页面必须登记路由与关联功能；没有功能归属的页面不允许上线。
2. 路由调整同步功能主文档“页面与交互”章节与前端测试。
3. 权限列必须与接口鉴权一致，冲突时以接口鉴权与冻结决策为准。
