# V1 扩展管理补全工程契约

2026-10-02 / P0-DOC r5。依据既有FR003 AC03–08、D025/D029和[扩展声明契约](V1-DGOS扩展声明与执行契约.md)。主OpenAPI引用[扩展生命周期](V1-extension.openapi.yaml)和[管理投影](V1-extension-management.openapi.yaml)，后者只承载新增工程操作，不是平行API。既有授权/确认/Run/幂等/引用保护不降级；本文不代表实现或验收通过。

## 操作与权限

| operationId | 公开入口 | 现有scope与前置 | 结果/幂等/并发 |
| --- | --- | --- | --- |
| createCustomSkill | POST /skills/custom | skill.install；主体资源授权、Session CSRF、confirmed | installed且disabled；requestId+主体+内容digest唯一；稳定skillId冲突409 |
| getSkillDefinition | GET /skills/{skillId}/definition | skill.read及当前所有权；no-store/读取审计 | 管理端可编辑内容；列表只摘要，非导出 |
| updateSkillDefinition | PATCH /skills/{skillId}/definition | skill.manage；Session CSRF；改Prompt需confirmed | baseVersion=stateVersion；原子内容/展示覆盖+receipt/audit；稳定ID和包SemVer不改 |
| translateSkill | POST /skills/{skillId}/translations | skill.manage + ai_task.submit、模型授权、显式confirmed | 202既有AITaskReceipt；相同requestId返原Task，改语言/字段/模型/源版本冲突 |
| applySkillTranslation | POST /skills/{skillId}/translations/apply | skill.manage + ai_task.read + artifact.read；显式confirmed | 原Task成功且绑定源版本/Skill/字段；读取Artifact校验后CAS写回，不接客户端译文覆盖 |
| listMcpTemplates | GET /mcp/templates | mcp.read | 只读可信模板与凭据字段元数据，无连接 |
| updateMcpConfig | PUT /mcp/{mcpId}/config | mcp.manage、主体授权、Session CSRF、confirmed | stateVersion CAS；停止且无活跃Run才能改；不自动启用/连接 |

统一错误沿既有ErrorResponse：字段/声明非法422 invalid_request，不兼容capability_mismatch；权限403 permission_denied/insufficient_scope；资源404；CAS/绑定/源变化409 version_conflict（执行既有request_conflict保持原契约）；需确认428 confirmation_required；秘密故障503 secret_unavailable/credential_unavailable。错误不含Prompt/凭据/主机路径，带requestId。事务receipt重放先核对完整主体/意图，成功返回原结果；过期确认不重新执行。无新的通用Agent权限或执行器。

## 自定义Skill与包子Skill

自定义Skill为主体所有的**声明式文本模板**，skillId由用户给定并校验稳定格式；server生成不冲突的local packageId及初始内容version=1.0.0，单子Skill映射。主体+packageId+skillId为实际内部键；HTTP skillId在主体可见域歧义时409，不能按同名第一项执行。包级安装/卸载与子Skill启停/展示编辑分离，依赖仍精确packageId/skillId/version/operationIds。

content.name/description/systemPrompt是有界私有文本。System Prompt不属于秘密凭据，但不能进audit、普通列表、日志、截图或无权响应。只在授权definition管理接口返回，字段级验证，不得为接收它而放宽整个config/input的秘密禁止。改名只写主体本地展示覆盖，既有签名包/子ID/引用/版本不改；相同展示名可列出但/技能名匹配歧义必须要求用户选择稳定ID，不能随机替换。

只有sourceType=custom允许编辑执行systemPrompt。编辑后stateVersion递增，暂停新调用至显式重启用；已存在Run冻结原定义快照，不改历史内容。签名包Prompt及操作结构保持不可变，需新受信版本才能改变执行语义；名称/描述翻译可以本地覆盖，Prompt翻译可预览但不可写入签名字节。包级删子Skill引用检查覆盖APP依赖/活跃Run/translation Task，失败无部分删除；移除保留历史missing/disabled和Artifact，不引入V2项目API。

## 自定义调用与翻译使用既有Task

自定义Skill仅注册operationId=text.chat，input={text}，options复用TextTaskOptions。确认请求及invoke都带相同options；规范化inputDigest同时绑定definition stateVersion/contentDigest和模型参数，不允许确认后改Prompt或换模型。执行检查Skill enabled、APP当前安装/digest/精确依赖、skill.execute、ai_task.submit、模型/额度；服务端把冻结Prompt与用户输入编排成受控文本请求，不接受调用者自报system角色/URL/工具操作。输入文本不提升权限，输出作为不可信内容展示。Run关联既有Task/Artifact；Run创建、Task准入及配额应同事务或同一持久幂等调度意图，崩溃后用原Task requestId恢复，不二次付出模型副作用。

翻译是显式的一次text.chat Task：UI展示目标语言、选中name/description/systemPrompt、模型及将发送的内容范围后确认。源字段与版本/digest在提交时冻结，参数遵[Provider文本参数契约](V1-Provider绑定与文本参数契约.md)，不制造“翻译成功”的假文本。translation requestId用于原Task幂等，Task的所有者为认证主体、target为平台注册翻译目标；不由caller传任意target。配额拒绝不留下可执行翻译任务或成功状态。Task查询/取消/Artifact读取复用现有ai_task.read/ai_task.cancel/artifact.read。翻译输出必须解析为所选字段的有界JSON，无其他字段/代码；格式错误保持原Skill，用户可查看失败原因。

apply为独立确认意图，有自己的requestId/baseVersion，服务端证明taskId/artifactId属于本主体且为该Skill、原源版本、目标语言和字段的成功翻译。只改所选字段；显示翻译按locale写localizedDisplay，不改变稳定身份；custom Prompt翻译修改执行内容则按语义编辑规则禁用新调用。源已变化409，失败不改变定义或消费其他任务。禁止将别人Task或普通文本生成Task冒充翻译Artifact。

## 在线来源与预览

沿用previewExtension/InstallRequest，不新增执行安装命令的后门。source接受既有受控引用或部署源策略允许的HTTPS地址；已登记的安装命令文本仅可由精确的注册解析器转换为一个受信引用，未知形式拒绝，永不启动shell/npm/npx/git命令。URL禁止凭据/query秘密、file/本机路径；下载走统一egress的host/CIDR/DNS pinning/TLS/重定向限制和有界响应。按受控包schema校验签名/来源/digest、包与全部子Skill、权限/风险，内容不可执行；未受信结果为rejected且不可安装。

preview绑定主体、规范化source、所选版本、包digest、模板版本、期限。返回摘要不含Prompt全文/凭据/绝对路径。install只消费该预览的不可变暂存字节；若必须重新取远端必须digest一致，变化409且重新preview，不安装新字节。失败不注册、不授权、不启动进程。r5给出的有界文本/数量是工程输入上限，部署可以更严格；不改变受信来源政策。

## MCP模板、配置与凭据

模板由部署受信目录发布templateId+精确version+source+非秘密config+credentialFields。setupState=ready/needs-credentials仅说明模板是否要求凭据，不冒充connected。D选择模板→填充非秘密配置→preview→明确补齐秘密→确认install；ordinary user install缺必填凭据应在保存/连接前拒绝。既有bundled发现/登记可以保留needs-credentials且不启动；用户通过config补齐再显式连接。无需凭据bundled服务也仅在既有自动启动策略与健康/权限通过时可启动。

credentials为writeOnly字段名→字符串，字段必须匹配模板credentialFields；只经HTTPS或受控native Secret边界提交，不能进入config.settings、普通receipt、previewDigest、日志或响应。服务端生成主体/服务绑定SecretRef并存SecretService；UI只看credentialStatus。更新省略credentials保留旧引用，提供则替换；没有隐式删除/空字符串清凭据行为。Secret写入失败不改配置；DB/audit失败对已写秘密持久补偿/撤销，旧凭据在新版本成功提交前保留；不可把敏感值明文放幂等receipt，秘密重试指纹使用服务端受控HMAC或Secret版本标识。

Config仍只暴露transport、runnerProfileId、endpointRef、settings。command/args/cwd/env由选定受信runner模板映射：settings仅允许已声明非秘密参数，路径限批准sandbox根，argv结构化而非shell拼接，秘密env由Secret短句柄注入，拒绝PATH/加载器/未批准环境覆盖。需要用户改命令/地址时只允许受信profile/destination的选择或其有界schema参数，不能直接执行任意文本。停止且无活跃Run后CAS编辑，失败保留旧配置/连接状态；重连/工具发现/删除使用既有生命周期语义。
