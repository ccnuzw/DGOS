# DGOS 安全基线

适用于所有版本的硬性安全要求。功能文档不得降级；例外必须进冻结决策。V1 身份、Secret、Provider、审计和额度的具体实现基线见 [ADR-0005](../06-决策记录/ADR/0005-V1身份秘密Provider治理与用量机器契约.md)、[ADR-0006](../06-决策记录/ADR/0006-V1事务存储与迁移恢复.md) 和 [ADR-0007](../06-决策记录/ADR/0007-V1秘密管理与Provider出站安全.md)。

## 1. 信任边界

| 边界 | 外部输入 | 必须的防护 |
| --- | --- | --- |
| 用户/管理接口 | 请求体、参数、文件 | 鉴权、校验、限流、输出编码 |
| 外部回调 | 回调报文 | 验签、金额与标识核对、幂等 |
| 外部 URL | 上游地址、用户提交 URL | host/CIDR 白名单、固定解析、重定向限制（SSRF） |

## 2. 身份与会话

- 权限一律服务端校验；路由隐藏不作为权限。
- 会话撤销后旧凭证必须失效；认证依赖故障时 fail-closed。
- 登录态存储位置与过期策略显式声明；V1 Web 会话和桌面宿主适配必须满足 ADR-0007 的传输与失效边界。

## 3. 密钥管理

- 密钥、Token、支付材料、签名 URL 不进入日志、错误响应、列表与导出。
- 敏感字段存储加密或单向哈希；Secret backend、短时句柄、轮换流程和旧值失效满足 ADR-0007，可演练。

## 4. 外部输入与 SSRF

- 所有外部输入校验类型、长度、范围、枚举。
- 抓取外部 URL 必须经统一出站组件限制协议、主机/CIDR、解析目标、TLS 与重定向；禁止携带凭证跨主机。Provider 连接测试和模型刷新同样适用。

## 5. 资金与数据完整性

- 金额使用 Decimal 或最小单位整数，禁止浮点。
- 唯一性、幂等与资金安全由数据库约束兜底。
- 关键写操作具备审计；删除必须有关联保护与二次确认。

## 6. 日志与敏感信息

- 日志包含 request_id；不包含密码、完整 Key、上游密钥、支付密钥、未脱敏个人信息。
- 错误响应不暴露内部细节、SQL 或堆栈。

## 7. 输出安全

- CSV/导出防公式注入并限制行数。
- 页面输出按上下文编码，防止注入；富文本按白名单清洗。

## 8. 可观测性入口

- health / ready / metrics 语义分离；指标入口受鉴权与网络边界保护。
- 生产禁止调试开关、默认密码与宽松 CORS。

## 9. 数据保留基线

| 数据类别 | 保留期 | 处理方式 |
| --- | --- | --- |
| 撤销会话、失败安装记录、暂存缓存 | 30 天，自各自终态/记录时间起算 | RetentionJob 先校验所有权和引用，失败保留并可重试 |
| 审计事件 | 180 天，自事件创建时间起算 | 只追加；清理需治理策略、previewDigest、checkpoint 和 eventId 关联 |
| 已提交 Task/Artifact | 用户明确删除前 | 删除先进入 hidden/removed；仍被引用时不得物理删除 |
| 用量明细与额度预留 | 由治理策略冻结；不得短于调查/审计关联需要 | UsageEvent 不可变；汇总可重建；未结算 reservation 必须 reconciliation |

## 10. 发布安全门禁

- 秘密扫描与依赖扫描无阻断级问题。
- 生产配置校验通过；示例值与占位符会被拒绝启动。
- 安全条款核对结果登记到[发布检查清单](发布/检查清单.md)与验证证据。
