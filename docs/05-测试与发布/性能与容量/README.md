本目录承接非功能需求与发布门禁中的性能与容量验证。全局约束与架构定义“必须达到什么”；本目录负责负载模型、环境、场景、执行、报告和证据。它不替代功能 E2E、并发集成测试或生产监控，也不因文档存在而证明性能门禁已经通过。

## 当前结论

- 当前没有有效性能批次；本目录只构成实现输入。指标、负载模型和批准人需在 DGOS 实现及部署拓扑稳定后冻结。

## 完成定义

性能门禁只有同时满足以下条件才能通过：

1. 发布负载配置有版本、批准人和摘要，批次绑定 commit/build/制品。
2. 场景按适用环境执行，命令退出码与机器可读报告有效。
3. 阶梯、稳态与过载恢复满足验收规范；预期容量拒绝与非预期错误分开统计。
4. 资源、队列、连接池与关键业务不变量证据齐全。
5. 压测后账务/数据一致性核对通过。
6. 负责人签字并关联到发布证据。
