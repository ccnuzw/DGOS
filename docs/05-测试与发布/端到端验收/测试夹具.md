# V1 E2E 测试夹具

## 1. 命名规则

所有动态值带 `run_id`：

```text
object_name=fixture-run_id
idempotency_key=case_id-run_id-sequence
```

密码和密钥只通过环境变量或测试运行器注入，不写入报告、截图、请求快照或本文档。

## 2. 身份夹具

| 夹具 | 创建方式 | 必须状态 | 使用用例 |
| --- | --- | --- | --- |
| `admin_active` | `bootstrapAdmin` 仅在空部署创建，后续用 `adminLogin` 建立测试 Session | active 管理员；凭据由环境变量注入 | `V1-E2E-11/12/14` |
| `admin_session_primary` | `adminLogin` 返回的 session；每次 run 独立创建 | active、带 `sessionVersion` | `V1-E2E-11/14` |
| `admin_session_revoked` | 从 primary session 派生后调用 `revokeAdminSession` | revoked，后续请求 401 | `V1-E2E-11` |
| `api_key_primary` | `createApiKey`，scope 使用测试专用最小权限 | active；secret 只在 runner 内存存在一次 | `V1-E2E-12` |
| `api_key_rotated` | `rotateApiKey`，保存 rotationGroup 不保存明文 | 新 Key active，旧 Key 在 overlap/终态 | `V1-E2E-12` |
| `user_new` | 待正式登录/注册接口实现后动态创建 | 初始不存在 | 待 V2 登录用例登记 |
| `user_active` | 待正式登录/注册接口实现后创建并完成必要前置 | active、依赖数据齐备 | 待 V2 登录用例登记 |

不同角色必须使用不同身份，不允许复用令牌。

## 3. 业务对象夹具

| 对象 | 固定要求 |
| --- | --- |
| `provider_account_primary` | `createProviderAccount` 创建测试主体拥有的 `openai-compatible` 账号；credential 通过 Secret fixture 注入；响应不得包含明文 |
| `provider_binding_primary` | `bindProviderAccount` 绑定一个测试 ProviderConfig；保存 account/config/version |
| `connection_test_*` | 每个场景使用独立 requestId：success、auth-failure、policy-blocked、timeout、cancelled |
| `governance_policy_v1` | `getGovernancePolicy` 读取基线；更新必须携带 baseVersion 和变更理由 |
| `retention_preview_v1` | 由清理服务生成 previewDigest；包含到期项、引用保护项和计数，不包含待删除原文 |
| `quota_policy_v1` | 测试主体/Provider/model 作用域，使用 requests 或 token metric；明确 hard limit、soft limit、window 和 policyVersion |
| `quota_task_primary` | AI Task 使用唯一 taskId；每次 Provider attempt 使用唯一 attemptId |

## 4. 外部依赖夹具

| 依赖 | 替身方式 | 断言 |
| --- | --- | --- |
| Provider API | 可控 adapter fixture；另设真实 `openai-compatible` contract 环境 | 记录调用次数、请求外形摘要、错误分类、无秘密响应；禁止保存 Authorization/body |
| DNS/网络 | 本地解析和出站策略 fixture | localhost、私网、link-local、云元数据和越界重定向在网络调用前被拒绝 |
| Audit Store | 正常存储、不可用、outbox 恢复三种模式 | 高风险操作有 eventId；不可用时 fail closed 或产生可恢复 outbox |
| Quota Store | 并发 CAS、重复 settle、服务重启和 reconciliation fixture | 不超发、不重复结算、恢复不重发 Provider |

禁止在证据中保存完整签名 URL、Authorization 或第三方密钥。

## 5. 金额与幂等夹具

| 项目 | 建议值 | 断言 |
| --- | --- | --- |
| 不适用 | V1 当前不包含收费和账务能力 | 不适用 |
| Provider/任务幂等键 | 每批次唯一 | 重放不重复提交或重复任务副作用 |
| 治理/额度幂等键 | `case_id-run_id-sequence` | 重复 policy update、retention sweep、reservation/settle 返回既有结果或稳定冲突 |
