# WP-W1-03 统一候选批次

运行脚本：

```sh
node scripts/w1-candidate-regression.mjs
```

脚本每次创建新的 `.herdr/evidence/w1-candidate-runs/<run-id>/`，不会覆盖旧批次。`manifest.json` 绑定 `code_version`、工作树 patch 摘要、资产摘要、运行环境、每条命令的 stdout/stderr、退出码、结果和限制。失败批次保持在原目录中。

批次将证据分为：

- `web-text-only`：文档检查、Web 类型检查、Provider 测试和 AI Task 集成测试。
- `native-workbench`：原生 Workbench 命令。没有设置 `DGOS_NATIVE_WORKBENCH_COMMAND` 时状态为 `blocked`，不借用 Web 结果。

Native 增量提供真实命令时，可用 `DGOS_W1_COMMANDS` 传入 JSON 命令清单；每项格式为 `{ "id": "...", "group": "native-workbench", "command": "...", "args": [...] }`。环境、数据库、外部 Provider 或签名 APP 的限制必须写入该批次 manifest 的 `limitations`，不能由历史报告补齐。
