## 最低断言维度

每个测试文件至少覆盖：

- HTTP 状态和业务 code/error_key。
- `request_id` 存在且可用于日志关联。
- 响应不包含密码、完整 Key、上游密钥和支付密钥。
- 关键数据状态及关联 ID。
- 失败场景没有额外上游调用、扣费或重复副作用。
- 测试结束时输出用例、run_id、构建标识和报告位置。
