# V1 发布门禁清单

## V1 适用性说明（2026-10-02）

支付下单/退款/资金回调签名、余额与财务审批不适用：FR-015仅模型调用用量与额度，不提供支付/计费。C节相关通用项不引入支付功能；替代验证为额度原子预留、唯一结算、上游调用事实及恢复一致性。导出公式注入在V1无导出入口时不适用，仍需验证未开放导出和秘密不泄露。其余权限/秘密/外部依赖/数据/灾备不能因此豁免。性能适用性、负载/阈值、RPO/RTO与观察窗口尚需按目标部署落实，不填虚构结果。

## A. 版本与构建

- [ ] 记录 commit、build_id、镜像 digest 和 migration 清单。
- [ ] 后端构建与现有回归、前端 typecheck/test/build 有当前构建证据。
- [ ] E2E 有目标环境批次记录，并覆盖相关 NFR。
- [ ] 依赖与镜像安全扫描无阻断级问题。
- [ ] 对冻结候选镜像执行 fresh scan，并绑定镜像 digest、扫描数据库时间和完整结果；历史扫描不能替代本项。
- [ ] 在同一冻结候选上执行 runtime canary，记录正常和负向边界；Docker 不可用时记录 blocker。

## B. 配置与秘密

- [ ] 所有示例密钥已替换，秘密扫描通过。
- [ ] 服务以生产模式通过启动配置校验；占位符与本地示例值会被拒绝启动。
- [ ] JWT、加密主密钥、内部 Token 等来自受控 secret；完成至少一次轮换演练并证明旧值失效。
- [ ] Secret rotation 在暂停写入窗口执行，保留旧 key 直到备份过期和恢复校验完成。
- [ ] 生产 CORS、TLS、安全响应头与内部接口网络边界已配置。

## C. 资金与数据

- [ ] 真实支付/外部依赖的下单、回调、查单、关单和退款验证通过（按项目适用）。
- [ ] 回调重放、金额篡改、签名失败测试通过。
- [ ] 并发写入、重复提交和补偿不会产生负余额、重复流水或丢失数据。
- [ ] 关键跨域写操作有事务边界与审计证明；故障注入证明失败时全量回滚。
- [ ] 导出/报表防公式注入并限制行数。

## D. 服务、依赖与可观测性

- [ ] 限流、熔断与依赖故障 fail-closed，返回稳定错误。
- [ ] 后台任务重复执行、部分失败与多实例竞态有证据。
- [ ] health/ready、metrics 鉴权、CORS 正反例、request_id 与秘密扫描通过。
- [ ] 性能与容量按[性能与容量执行空间](../性能与容量/README.md)完成并达标（如适用）。
- [ ] readiness 在 PostgreSQL、Redis、root key、ciphertext 和信任根全部可用后才通过；依赖缺失时 fail closed。

## E. 数据、备份与恢复

- [ ] migration 在生产副本或生产规模数据上验证。
- [ ] 发布前备份完成且可定位。
- [ ] 按[恢复手册](恢复手册.md)完成恢复演练并记录实际 RPO/RTO。
- [ ] 多存储备份同时覆盖数据库、包文件、加密 Secret 记录和引用摘要；root key 独立恢复。
- [ ] 数据保留与清理任务符合[安全基线](../安全基线.md)。

## F. 发布批准

- [ ] 产品负责人确认范围与已知限制。
- [ ] 技术负责人确认实现、迁移、回滚和监控。
- [ ] 业务/财务确认相关资金与对账口径（如适用）。
- [ ] 发布负责人填写[验证证据](验证证据.md)并批准窗口。
- [ ] 任何豁免记录风险、批准人、截止日期和补偿措施；资金一致性、真实依赖、密钥与备份恢复不得豁免。
