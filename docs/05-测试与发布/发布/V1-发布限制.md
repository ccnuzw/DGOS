# V1 发布限制

本页是发布门禁的强制限制清单。任何本地门禁通过都不能覆盖以下未完成项。

## 当前可交付范围

- `pnpm preview:up` 只提供本地 Compose 技术预览。
- 预览使用受控本地 Provider fixture，不证明真实外部 Provider、TLS、账号或限流行为。
- `pnpm candidate:freeze` 生成源文件 SHA-256 manifest；dirty 工作树会被标记为不可发布。
- `pnpm release:gate` 聚合 migration、secret scan、docs check 和 release docs gate；任一失败都输出 `blocked`。

## 明确未通过的发布条件

- 未提供 Developer ID 签名、公证和安装升级证据时，不得标记 macOS release-ready。
- 未在目标环境完成真实 Provider、TLS/CA、Secret/KMS 和 DNS/SSRF 验证时，不得标记 production-ready。
- 未完成 fresh image、备份恢复、回滚演练、RPO/RTO 与性能审批时，不得标记 V1 正式发布。
- fixture、debug bundle、旧候选或历史 evidence 不得拼接成当前候选通过。

## 证据要求

每次候选必须绑定唯一 commit、工作树状态、文件 hash、门禁输出和限制列表。源码改变后必须重新冻结候选；不得修改已生成候选。
